## algorithm=factorial · input {"n":3}
  1. Calcula fact(3) = 3!, com recursão.
  2. Chama fact(3).
  3. Chama fact(2).
  4. Chama fact(1).
  5. fact(1): caso base, devolve 1.
  6. fact(2) = 2 × fact(2 - 1) = 2 × 1 = 2.
  7. fact(3) = 3 × fact(3 - 1) = 3 × 2 = 6.
  8. fact(3) = 6, com 3 chamadas.

## algorithm=fibonacci · input {"n":3}
  1. Calcula fib(3), com duas chamadas recursivas por passo.
  2. Chama fib(3).
  3. Chama fib(2).
  4. Chama fib(1).
  5. fib(1): caso base, devolve 1.
  6. Chama fib(0).
  7. fib(0): caso base, devolve 0.
  8. fib(2) = fib(2 - 1) + fib(2 - 2) = 1 + 0 = 1.
  9. Chama fib(1).
 10. fib(1): caso base, devolve 1.
 11. fib(3) = fib(3 - 1) + fib(3 - 2) = 1 + 1 = 2.
 12. fib(3) = 2, com 5 chamadas (muitas repetidas).

## algorithm=hanoi · input {"n":3}
  1. Move 3 discos do poste A para o poste C, com o poste B como auxiliar.
  2. Chama h(3,A,C).
  3. Chama h(2,A,B).
  4. Chama h(1,A,C).
  5. Um só disco: move o disco 1 de A para C.
  6. Move o disco 2 de A para B.
  7. Chama h(1,C,B).
  8. Um só disco: move o disco 1 de C para B.
  9. 2 discos passaram de A para B em 3 movimentos.
 10. Move o disco 3 de A para C.
 11. Chama h(2,B,C).
 12. Chama h(1,B,A).
 13. Um só disco: move o disco 1 de B para A.
 14. Move o disco 2 de B para C.
 15. Chama h(1,A,C).
 16. Um só disco: move o disco 1 de A para C.
 17. 2 discos passaram de B para C em 3 movimentos.
 18. 3 discos passaram de A para C em 7 movimentos.
 19. Feito: 7 movimentos (2^3 - 1) e 7 chamadas.

  2. Chama fib(4).
  3. Chama fib(3).
  4. Chama fib(2).
  5. Chama fib(1).
  6. fib(1): caso base, devolve 1.
  7. Chama fib(0).
  8. fib(0): caso base, devolve 0.
  9. fib(2) = fib(2 - 1) + fib(2 - 2) = 1 + 0 = 1.
 10. Chama fib(1).
 11. fib(1): caso base, devolve 1.
 12. fib(3) = fib(3 - 1) + fib(3 - 2) = 1 + 1 = 2.
 13. Chama fib(2).
 14. Chama fib(1).
 15. fib(1): caso base, devolve 1.
 16. Chama fib(0).
 17. fib(0): caso base, devolve 0.
 18. fib(2) = fib(2 - 1) + fib(2 - 2) = 1 + 0 = 1.
 19. fib(4) = fib(4 - 1) + fib(4 - 2) = 2 + 1 = 3.
 20. fib(4) = 3, com 9 chamadas (muitas repetidas).
