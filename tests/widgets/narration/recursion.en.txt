## algorithm=factorial · input {"n":3}
  1. Compute fact(3) = 3!, recursively.
  2. Call fact(3).
  3. Call fact(2).
  4. Call fact(1).
  5. fact(1): base case, return 1.
  6. fact(2) = 2 × fact(2 - 1) = 2 × 1 = 2.
  7. fact(3) = 3 × fact(3 - 1) = 3 × 2 = 6.
  8. fact(3) = 6, with 3 calls.

## algorithm=fibonacci · input {"n":3}
  1. Compute fib(3), with two recursive calls each time.
  2. Call fib(3).
  3. Call fib(2).
  4. Call fib(1).
  5. fib(1): base case, return 1.
  6. Call fib(0).
  7. fib(0): base case, return 0.
  8. fib(2) = fib(2 - 1) + fib(2 - 2) = 1 + 0 = 1.
  9. Call fib(1).
 10. fib(1): base case, return 1.
 11. fib(3) = fib(3 - 1) + fib(3 - 2) = 1 + 1 = 2.
 12. fib(3) = 2, with 5 calls (many repeated).

## algorithm=hanoi · input {"n":3}
  1. Move 3 disks from peg A to peg C, using peg B.
  2. Call h(3,A,C).
  3. Call h(2,A,B).
  4. Call h(1,A,C).
  5. One disk: move disk 1 from A to C.
  6. Move disk 2 from A to B.
  7. Call h(1,C,B).
  8. One disk: move disk 1 from C to B.
  9. 2 disks went from A to B in 3 moves.
 10. Move disk 3 from A to C.
 11. Call h(2,B,C).
 12. Call h(1,B,A).
 13. One disk: move disk 1 from B to A.
 14. Move disk 2 from B to C.
 15. Call h(1,A,C).
 16. One disk: move disk 1 from A to C.
 17. 2 disks went from B to C in 3 moves.
 18. 3 disks went from A to C in 7 moves.
 19. Done: 7 moves (2^3 - 1) and 7 calls.
