Aula 10 · Árvores binárias

Nesta aula vais implementar métodos recursivos sobre árvores binárias genéricas e perceber, passo a passo, a ordem pela qual cada percurso visita os nós.

In this lab you will implement recursive methods on generic binary trees and see, step by step, the order in which each traversal visits the nodes.

Objetivos

  • Escrever funções recursivas sobre BTree<T>
  • Distinguir pré-ordem, em-ordem, pós-ordem e largura
  • Usar uma fila para percorrer por níveis

2. Ver os percursos

Em pré-ordem visita-se o nó antes das subárvores; em-ordem, entre a subárvore esquerda e a direita; em pós-ordem, depois de ambas.

3. Exercícios

Os exercícios 1 a 5 são para fazer na aula. O 6 é extra.

Implementa int numberNodes(), que devolve o número de nós da árvore. Uma árvore vazia tem 0 nós.

Implement int numberNodes(), returning the number of nodes in the tree. An empty tree has 0 nodes.

Dica

O número de nós de uma árvore é 1 (a raiz) mais os nós da subárvore esquerda mais os da direita. Cria um método privado que recebe um nó.

Solução 
private int numberNodes(BTNode<T> n) {
  if (n == null) return 0;
  return 1 + numberNodes(n.getLeft()) + numberNodes(n.getRight());
}
