uc-date

From a deadline

  • short (default): 12 nov
  • long: 12 de novembro de 2025
  • weekday: quarta-feira, 12 nov
  • with-time: 12 nov, 16:00
  • weekday + with-time: terça-feira, 2 dez, 21:00
  • month only: janeiro 2026
  • to be scheduled (date: null): a anunciar
  • unknown id keeps the fallback text: fallback text

From a value

  • short: 16 set
  • long: 16 de setembro de 2025
  • weekday: terça-feira, 16 set
  • with-time is ignored without a time: 16 set
  • invalid value keeps the fallback text: fallback text
  • no attributes keeps the fallback text: fallback text
