Começar

O ficheiro course.js

O course.js guarda o que muda de ano para ano ou aparece em mais de uma página. É JavaScript, mas só tem uma atribuição: um objeto em window.UC_COURSE. Só o título é obrigatório.

A forma do ficheiro

window.UC_COURSE = {
  code: "AP0001",
  title: "Algoritmos e Programação",
  edition: "2025/26",
  semester: { start: "2025-09-15", weeks: 12 },
  pages: ["home", { id: "weeks", href: "semanas.html" }],
  deadlines: [
    { id: "t2", title: "Entrega do trabalho 2", kind: "submission", date: "2025-11-28", time: "23:59" },
  ],
};

Cada página carrega-o antes do kit (ver o <head> de cada página). O kit lê-o uma vez, completa o que falta com os valores por omissão e avisa na consola do browser, com mensagens [uc-kit] course.js: …, quando um valor não é válido. Um erro num campo nunca impede a página de aparecer.

Nas tabelas, a coluna Necessário diz quando preencher o campo:

  • Obrigatório sem ele o kit avisa e usa o <title> da página.
  • Recomendado sem ele há funcionalidades que não aparecem (por exemplo, sem semester.start não há datas nas semanas).
  • Opcional tem um valor por omissão razoável.

Só valores, sem código

O script de manutenção uc-site.py lê o course.js sem o executar. Por isso o ficheiro só pode ter valores:

  • comentários (// e /* */);
  • uma única atribuição window.UC_COURSE = { … };;
  • antes dela, constantes opcionais: const NOME = valor;;
  • valores: objetos, listas, textos (com ", ' ou `), números, true, false e null, com ou sem vírgula no fim;
  • uma constante usada como valor, textos juntos com + e ${NOME} dentro de um texto com `.

As constantes evitam repetir um endereço:

const ORIGINAL = "https://www.dcc.fc.up.pt/~fds/aulas/pi/2526/";

window.UC_COURSE = {
  // …
  platforms: [
    { label: "Pautas", url: ORIGINAL + "evaluation/" },
    { label: "Site antigo", url: `${ORIGINAL}index.html` },
  ],
};

Funções, new Date(), chamadas de métodos, ... e outras atribuições não são permitidas. O browser aceita-as, mas o uc-site.py para nesse ponto e diz a linha:

ERRO   course.js:3  'new' não é um valor: o course.js só pode ter valores (texto, números, listas, objetos)

O índice é criado pelo uc-site.py; o botão «Pesquisar» está em <uc-page>.

Páginas

Cada entrada de pages é um identificador ou um objeto com id, href e label:

pages: [
  "home",                                          // index.html, "Início"
  { id: "weeks", href: "semanas.html" },           // identificador do kit, ficheiro próprio
  { id: "projects", href: "projetos.html", label: { pt: "Projetos", en: "Projects" } },
  { id: "about", href: { pt: "sobre.html", en: "about.html" } },   // um ficheiro por língua
],
  • id identifica a página; é o valor de <uc-page current>.
  • href é relativo ao course.js, por isso funciona igual em páginas de subpastas. Um LocalizedText indica um ficheiro por língua.
  • label é o nome na navegação; obrigatório para identificadores que não são do kit.

Os identificadores do kit já têm ficheiro e nome:

Campos de um membro da equipa
CampoTipoDescrição
nametextoObrigatório.
urlURLPágina pessoal; o nome passa a link.
emailtextoMostrado como link mailto:.
role"coordinator", "lecturer", "assistant" ou LocalizedTextOs três papéis do kit são traduzidos (Regente, Docente, Práticas); qualquer outro texto aparece como está.

Horário

Uma entrada por aula semanal. Uma turma com duas aulas por semana tem duas entradas, que <uc-timetable> junta numa linha ("3.ª e 5.ª").

schedule: [
  { type: "lecture", class: "T1", day: 2, start: "14:00", end: "15:00", room: "FC4 0.41" },
  { type: "lecture", class: "T1", day: 4, start: "14:00", end: "15:00", room: "FC4 0.41" },
  { type: "lab", class: "PL2", day: 2, start: "16:00", end: "18:00", room: "FC6 1.65" },
  { type: "lab", class: "PL7", day: 2, start: "16:00", end: "18:00", room: "FC6 0.08",
    staff: "Eduardo Marques", note: "Só nas semanas ímpares" },
],
Campos de uma aula do horário
CampoTipoDescrição
type"lecture", "lab", "tutorial" ou textoObrigatório. Os três tipos do kit são traduzidos (Teóricas, Práticas laboratoriais, Teórico-práticas); outro texto é um tipo próprio, com o nome dado em scheduleTypes ou tal como está escrito.
classtextoObrigatório. A turma, por exemplo "T1" ou "PL2".
dayWeekdayObrigatório. O dia da semana, de 1 (segunda) a 7 (domingo).
start, endTimeObrigatórios. Início e fim da aula.
roomHTMLTextA sala; pode ser um link (planta, reserva).
stafftexto ou lista de textosOs docentes, com os nomes escritos como em team. Sem este campo, são as pessoas da equipa cujo classes inclui a turma, por isso normalmente não é preciso.
noteHTMLTextUma nota curta, por exemplo "Só nas semanas ímpares".

Uma entrada a que falte type, class, day, start ou end não aparece, e a consola diz qual é.

Plataformas

Os links externos do grupo "Plataformas" da navegação. As mesmas entradas dão o nome do juiz nas listas de problemas (<uc-problems>).

platforms: [
  { id: "mooshak", label: "Mooshak", url: "https://mooshak.dcc.fc.up.pt/~edados/" },
  { id: "codeforces", label: "Codeforces", url: "https://codeforces.com", hidden: true },
],
Campos de uma plataforma
CampoTipoDescrição
labelLocalizedTextObrigatório. O nome na navegação e na etiqueta do juiz.
urlURLObrigatório.
idtextoNome curto, usado em data-judge="codeforces". Sem ele, data-judge é comparado com label, sem distinguir maiúsculas nem acentos.
hiddenbooleanoCom true, a plataforma não aparece na navegação, mas as listas de problemas conhecem-na (um juiz usado só numa série).

Prazos

Um prazo escreve-se uma vez e aparece onde fizer falta: na lista de próximas datas, dentro da semana em que cai, no cartão "Esta semana" e na tabela da avaliação.

deadlines: [
  { id: "t2", title: "Entrega do trabalho 2", date: "2025-11-28", time: "23:59", kind: "submission",
    note: "Pela plataforma de entregas", url: "trabalhos/t2.html" },
  { id: "quiz5", title: "Quiz 5", date: "2025-11-17", end: "2025-11-24", kind: "quiz" },
  { id: "teste", title: "Teste prático", date: "2025-12-10", time: "14:00", kind: "assessment",
    duration: 105, location: "Laboratórios 1 e 2",
    shifts: [{ time: "14:00" }, { time: "16:00", location: "Laboratório 1" }],
    url: "teste.html", links: [{ label: "Enunciado de 2024/25", url: "avaliacao/teste-2425.pdf" }] },
  { id: "exame", title: "Exame, época normal", date: "2026-01", kind: "exam" },   // dia por marcar
  { id: "recurso", title: "Exame de recurso", date: null, kind: "exam" },        // a marcar
],
Campos de um prazo
CampoTipoDescrição
idtextoObrigatório e único. Usado por <uc-date deadline> e <uc-event deadline>.
titleLocalizedTextObrigatório.
dateISODate, "AAAA-MM" ou nullDia do prazo; só o mês quando o dia não se sabe; null quando está por marcar.
timeTimeHora de início ou limite.
endISODateÚltimo dia, para prazos de vários dias (um quiz aberto uma semana). Conta como próximo até acabar.
kind"assessment", "exam", "quiz", "submission", "other"Tipo: muda a etiqueta e permite filtrar (kind="assessment exam" nos componentes). Por omissão "other".
noteHTMLTextLinha secundária curta: turnos, salas, plataforma.
urlURLPágina com mais informação; o título passa a link.
links{ label, url }[]Links extra (resultados, turnos).
durationMinutesDuração da prova. Com time, a hora de fim é calculada ("14:00–15:45").
locationHTMLTextSalas, ou um link para a distribuição por salas (pode levar data-auth).
shiftsShift[]Turnos, quando a mesma prova se faz mais de uma vez. Aparecem em vez de time, que continua a ser a hora do primeiro turno (para ordenar).

Cada turno (Shift) é { time, end, date, location, note }, e só time é obrigatório. end é por omissão time mais duration; date é o dia do prazo (muda-se para uma prova feita em dois dias); location e note aparecem só junto a esse turno. Com turnos ou com duration, os componentes que mostram o prazo mostram também as horas ("14:00 e 16:00", "14:00–15:45"), e <uc-assessment-info> mostra tudo num cartão.

Avisos

notices: [
  { date: "2025-11-27",
    text: "Saíram as notas do teste 1. Ver <a href=\"avaliacao.html\">Avaliação</a>." },
  { date: "2025-12-01", text: "Não há aula teórica na segunda-feira.",
    details: "A matéria passa para quarta." },
],
Campos de um aviso
CampoTipoDescrição
dateISODateObrigatório. Os avisos mostram-se do mais recente para o mais antigo, e um aviso com data futura só aparece nesse dia: podem escrever-se com antecedência.
textHTMLTextObrigatório. Uma linha.
detailsHTMLTextSegunda linha, opcional.

Edições

Um ficheiro editions.js na pasta da cadeira, acima das pastas dos anos, lista todas as edições. O course.js de cada ano aponta para ele com editions: "../editions.js", e <uc-page> mostra o botão "Outros anos" e, nas edições antigas, um aviso com o link para a atual.

EDados/
  editions.js      ← lista das edições (window.UC_EDITIONS)
  2425/course.js   ← editions: "../editions.js"
  2526/course.js   ← editions: "../editions.js"
 
window.UC_EDITIONS = [
  { label: "2025/26", href: "2526/" },   // a primeira é a edição atual
  { label: "2024/25", href: "2425/" },
  { label: "2023/24", href: "https://www.dcc.fc.up.pt/~fds/aulas/EDados/2324/" },
];
Campos de uma edição
CampoTipoDescrição
labeltextoObrigatório. Igual ao edition do course.js desse ano: é assim que o kit sabe em que edição está a página.
hrefURLObrigatório. Relativo ao editions.js ("2526/"), ou um endereço completo para anos que estão noutro sítio.

O kit carrega o ficheiro sozinho, também a partir do disco. Se não o encontrar, escreve um aviso na consola e a página fica como sem editions. Como o ficheiro está fora das pastas dos anos, acrescentar um ano novo atualiza os sites anteriores sem lhes mexer (ver Novo ano letivo).

Erros comuns

O kit avisa na consola (F12) com mensagens começadas por [uc-kit], e o uc-site.py encontra os mesmos erros sem abrir o browser, com a linha de cada um. Estes são os casos mais frequentes:

Erros comuns no course.js
SintomaCausa e solução
O cabeçalho mostra o título do separador e a navegação só tem "Início"; na consola, SyntaxErrorErro de sintaxe no course.js: falta uma vírgula entre campos, sobra uma chaveta ou uma aspa ficou por fechar. A consola indica a linha.
window.UC_COURSE is missingO course.js não foi carregado, ou foi carregado depois do kit. Confirmar o caminho (../course.js numa subpasta) e que vem antes de uc-kit.js, sem defer.
has an invalid date "2025-9-1"As datas levam zeros: "2025-09-01".
has unknown kind "teste"kind aceita só assessment, exam, quiz, submission e other; o nome que se mostra vai em title.
is not a built-in page and needs an hrefUma página com identificador próprio precisa de href e label.
As semanas não têm datasFalta semester.start, ou a data não é válida.
A semana 1 começa uma semana mais cedo ou mais tardeA semana 1 é a semana do calendário (segunda a domingo) que contém semester.start. Confirmar o dia e as interrupções em breaks.
Um aviso não apareceTem uma data futura: só aparece nesse dia. Para testar, abrir a página com ?today=.
Aspas partem o texto de um avisoDentro de um texto entre ", as aspas do HTML escrevem-se \", ou usam-se plicas à volta do texto.
Tudo aparece num dia erradoFicou um today no course.js. Apagar a linha.
