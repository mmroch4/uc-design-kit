Escreve maximo(lista), que devolve o maior elemento de uma lista não vazia sem usar a função max.

Dica

Guarda o primeiro elemento numa variável e percorre os restantes, trocando-o sempre que encontrares um maior.

Solução 
def maximo(lista):
    maior = lista[0]
    for x in lista[1:]:
        if x > maior:
            maior = x
    return maior
