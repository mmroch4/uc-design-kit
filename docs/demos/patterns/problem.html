[P042] Soma dos dígitos

O problema

Dado um número inteiro positivo, calcula a soma dos seus dígitos. Por exemplo, a soma dos dígitos de 2025 é 2 + 0 + 2 + 5 = 9.

Input

Uma linha com um inteiro N (1 ≤ N ≤ 1018).

Output

Uma linha com a soma dos dígitos de N.

Exemplo

InputOutput
 
2025
 
9

Submete a solução na plataforma indicada na página de semanas.
