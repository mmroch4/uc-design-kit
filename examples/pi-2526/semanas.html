SemanasWeeks

Tudo o que acontece em cada semana: aulas teóricas, slides, guião da aula prática e sumários. As aulas práticas vão de quarta a terça; o guião de cada aula aparece na semana em que começa.

Everything that happens each week: lectures, slides, lab guide and summaries. Lab classes run from Wednesday to Tuesday; each guide is listed in the week it starts.

Lectures 4 and 5 · slides 1b and 2
Lab class
Class 3: Mooshak, characters and functions
Sumários
  1. (3 mar) Introdução ao C (cont.): Dados do tipo char. Escrita e leitura de carateres, output da tabelas ASCII, leitura e escrita com getchar() e putchar(). Funções. A função isPrime(). Chamada de funções e passagem de argumentos. A instrução return. A função main(). Vetores (arrays): declaração, indexação, inicialização. Exemplos. Tipos primitivos de dados: integers, floats, doubles and characters. Qualificadores unsigned, short e long. Escrita de números em binário. Verificar se um número tem dígitos repetidos.
  2. (5 mar) Arrays multidimensionais. Exemplo com baralho de cartas. Exemplo com geração de aleatórios. Adição de matrizes. Strings e funções com arrays como argumentos. String como vetor de carateres. leitura de strings (scanf() and gets()), escrita (printf() and puts()). Arrays como argumentos de funções. Função para remover duplicados de um array.
Summaries
  1. (3 Mar) Introduction to C (cont.) – Char data type, character reading and writing, ASCII table output, reading and writing with getchar() and putchar(). Functions. The isPrime() function. Function calls and argument passing. The return statement. The main() function. Arrays (vectors): declaration, indexing, initialization. Examples. Primitive data types: integers, floats, doubles, and characters. Unsigned, short, and long qualifiers. Writing numbers in binary. Checking if a number has repeated digits.
  2. (5 Mar) Multidimensional arrays. Example with a deck of cards. Example with random number generation. Matrix addition. Strings and functions with arrays as arguments – Strings as character arrays. Reading strings (scanf() vs gets()), writing (printf() and puts()). Arrays as function arguments – Function to remove duplicates from an array.

Class 4: Arrays and strings (I)
Sumários
  1. (10 mar) Função para verificar se um elemento ocorre num vetor, comprimento de uma string, inversão de uma string, cópia de uma string origem para destino, concatenação de strings, procura e comparação. Apontadores: organização da memória, noção de apontadores em C, declaração de um apontador, endereço de uma variável (operador &), valor apontador por uma variável apontador (operador *), atribuição, apontadores como argumentos de funções, apontadores e arrays, funções que retornam apontadores. Revisão de algumas funções de manipulação de strings representadas por vetores de carateres mas agora trabalhadas com apontadores para carateres.
  2. (12 mar) Apontadores: Acesso a matrizes multidimensionais. Exercícios sobre matrizes: 1) determinar algumas estatísticas relacionadas com os registo dos resultados obtidos por alunos em diferentes cursos (matriz com notas); 2) resposta a questões relacionadas com o registo anual de precipitação num conjunto de estações (matriz com valores de precipitação).
Summaries
  1. (10 Mar) Function to check if an element occurs in an array, string length, string reversal, copying a string from source to destination, string concatenation, searching, and comparison. Pointers – Memory organization, concept of pointers in C, pointer declaration, address of a variable (operator &), dereferencing a pointer variable (operator *), assignment, pointers as function arguments, pointers and arrays, functions that return pointers. String manipulation using pointers – Revisiting some string manipulation functions previously represented as character arrays, now implemented using character pointers.
  2. (12 Mar) Pointers – Accessing multidimensional arrays. Exercises on matrices - 1) determining some statistics related to the records of results obtained by students in different courses (matrix with grades); 2) solving questions related to annual precipitation records in a set of weather stations (matrix containing precipitation values).
