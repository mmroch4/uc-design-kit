Linux Commands Reference

Command Descrption Example Explanation
lsList the files and folders in the current directory.ls -lList the files in detailed format.
manShow the manual for a command.man lsShow the manuel of the command ls.
cdChange to another directory.cd /home/userGo to the directory /home/user.
pwdShow the path for the currect directory.pwdShow the complete path of the current directory.
mkdirCreate a new directory.mkdir dir_docsCreate the directory dir_docs.
rmdirRemove a empty directory.rmdir dir_docsRemove dir_docs, if it is empty.
rmRemove files or folders.rm -r folderRemove a folder and all its content.
cpCopy files or folders.cp file.txt backup/Copy file.txt to the folder backup/.
mvMove or rename files and directories.mv file.txt new_name.txtRename file.txt to new_name.txt.
findSearch for files and directories on the system.find /home -name "*.txt"Search text files (.txt) in /home.
grepSearch for text patterns within files.grep "error" log.txtSearch the word "error" inside of log.txt.
tarCompress or extract files.tar -cvf backup.tar folder/Create a file backup.tar with the files of the folder/.
zip / unzipCompressing and decompressing ZIP files.zip file.zip doc.txtCompress doc.txt in file.zip.
wgetDownloads files from the web.wget http://site.com/file.zipDownload file.zip from specific site.
curlData transfer via various protocols.curl -O http://site.com/file.zipDownload the file.zip used curl.
catDisplay the contents of a file.cat text.txtDisplay the contents of the file text.txt.
lessView files page by page.less text.txtAllow you to browse the file text.txt.
nanoSimple text editor in the terminal.nano text.txtOpen/create text.txt to edition on nano.
echoDisplay messages in the terminal.echo "Hello World!"Display the message "Hello World!" in the terminal.
exitExit the current terminal session.exitClose the terminal or end the SSH session.
wcCount lines, words, and characters in files.wc -l file.txtCount the number of lines in file.txt.
headShow the first few lines of a file.head -n 5 file.txtShow the first 5 lines of file.txt.
tailShow the last few lines of a file.tail -n 8 file.txtShow the last 8 lines of file.txt.
touchCreate an empty file or updates the modification date.touch new.txtCreate new.txt if it doesn't exist or updates its date.
dateDisplay the current date and time.dateDisplay the system date and time.
uniqRemove duplicate lines from a file.sort lists.txt | uniqRemove duplicates from the sorted list.
cutExtract specific parts of lines in files.cut -d"," -f2 data.csvDisplay only the ages from a file dados.csv organized as Name,Age.
trReplace or remove characters in text.echo "test" | tr 'e' 'a'Replace "e" by "a" on word "test" (result: tast).
