Course description · CC1003

About the course

The course introduces the fundamental concepts of imperative programming, emphasizing algorithms and modularity, using the C programming language. Focus is placed on practical problem solving, the implementation of basic algorithms for counting, searching, and sorting, and the clarity and quality of code.

Learning outcomes

Upon completing this course, students will be able to:

  • use the syntax and semantics of core C constructs;
  • write, test, and execute programs to solve simple problems from informal specifications;
  • implement basic algorithms in C;
  • apply pointers to process arrays and strings;
  • employ dynamic memory allocation;
  • use standard C library functions for string processing and file I/O;
  • apply structured programming techniques;
  • work with basic data structures such as linked lists and trees.

Syllabus

  1. Introduction to the C programming language: brief historical context, characteristics, advantages and disadvantages, risks, and precautions in its use.
  2. Fundamentals of the C language: syntactic structure of programs, directives, declarations, expressions, compilation and execution.
  3. Basic types (integers, floating point, characters). Control constructs, loops, function definition, formatted input and output.
  4. Indexed variables. Fundamental algorithms: counting, searching, and sorting. Processing character strings.
  5. Program organization: header files and standard libraries.
  6. Error detection and prevention. Use of debuggers and assertions.
  7. Introduction to the C memory model. Programming with pointers. Use of pointers for processing strings and indexed variables.
  8. Recursion. Solving simple problems using iterative and recursive algorithms.
  9. Definition of new data types (struct, union).
  10. File operations: reading and writing.
  11. Basic data structures: linked lists and trees.

Teaching methods

Lectures

Structured presentation of fundamental concepts, supported by slide presentations, with illustrative programming examples and the interactive resolution of exercises, fostering active student participation.

Laboratory classes

Hands-on practice on the computer through the resolution of programming problems, using development tools (editors, debuggers, compilation systems, and automatic testing systems) to support error detection and correction, encouraging autonomy and critical thinking.

Continuous practice and assessment

Use of automatic grading systems (e.g., Mooshak), which enable regular practice, immediate feedback, and continuous monitoring of learning, consistent with a pedagogical approach focused on the development of practical skills.

Classes involve the use of the C programming language, solving exercises designed to practice programming skills, and solving exercises intended for assessment purposes.
