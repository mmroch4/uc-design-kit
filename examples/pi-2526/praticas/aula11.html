Exercício 1) Stacks and Queues with LinkedList

In this class you are expected to use the same LinkedList structure from Exercise 1 of the previous class (Pratical Class #10), recall that a stack follows a LIFO (Last In, First Out) policy and a queue follows a FIFO (First In, First Out) policy.

This exercise also introduces the use of header files (.h) to separate the interface of a data structure from its implementation. Consider the following organization:

  • linkedlist.h : declares the structures and function prototypes
  • main.c : includes linkedlist.h and uses the functions
Now, consider the given header file linkedlist.h:


  1. Implement the functions declared in linkedlist.h in a file linkedlist.c. For each function, indicate its time complexity using Big-O notation in a comment above the function.
  2. A stack is commonly used to check whether an expression has balanced brackets. Write a program (in main_brackets.c) that reads a string from standard input and uses your stack implementation to verify whether the brackets are balanced. Your program should handle (, ), [, ], {, and }.
    The program should print "Balanced" or "Not balanced" accordingly.
    Example:
    • [PI056] Well-Balanced Expressions
        You can now read the statement of problem PI056 carefully and try to submit an Accepted solution. You only need to adapt your solution.

  3. A queue can be used to simulate a service line. Write a program (in main_hospital_triage.c) that simulates a hospital triage queue. Patients arrive with a name and a priority level (1 = urgent, 2 = normal).
    The program should read commands from standard input:
    • ADD [name] [priority] — adds a patient to the queue
    • NEXT — removes and prints the next patient from the queue (urgent patients always come first)
    • LIST — prints all patients currently in the queue
    • EXIT — ends the program
    Hint

    - use two separate queues, one for each priority level.


    Example: 
    
   ADD Alice 2
   ADD Bob 1
   ADD Carol 2
   NEXT
   Next patient: Bob (priority 1)
   LIST
   Alice (priority 2)
   Carol (priority 2)

Exercise 3) Reading and Writing Files

  1. Write a simple program that reads a given number of lines from the standard input and writes those lines to a text file. Example: 
    
Number of lines: 4
Line 1
Line 2
Line 3
Line 4
  2. Write a program that reads the text file created in the previous exercise and stores the file's lines in an array.
  3. Write a function int number_lines(char *file_name); that returns the number of lines in a file.
  4. Write a program to count the words contained in a file. Consider that words are sequences of “normal characters” (e.g., letters, digits, or punctuation marks) separated by “whitespace characters” (spaces, tabs, or newline characters, i.e., ' ', '\t', or '\n').
  5. Write a program that reads the contents of two text files, "file1.txt" and "file2.txt", and writes a new file (named "union.txt") obtained by merging the contents of the two original files.
  6. Write a function that reads a list of contacts stored in a file named "contacts.txt" without using fscanf. Each contact is defined by a person’s name and their mobile phone number, and the file must follow this format: 
    
joaquina, 016002222
ana pinto, 0671445566
joao costa, 8442222
    That is, each name is followed by a comma (',') and each mobile number ends with a newline character ('\n'). Names and mobile numbers may be preceded by spaces, as shown in the example above.
    The implemented function should display the names and contacts read from the file on the screen (standard output).
  7. Modify the previous program to include an efficient search function for a phone contact.
    To do this, create a new file named "sorted_contacts.txt" containing all the original phone contacts sorted in alphabetical order by the person's name.
    Also, create a function that allows searching for a contact by the person's name using binary search (which is efficient in terms of performance).
    The function should return the mobile phone number if the contact exists, and -1 otherwise.
  8. To manage information about students enrolled in a given course, it is necessary to store the following data:
    • Student's name (a string with a maximum of 60 characters)
    • Student's ID number (mechanographic number)
    • Grade obtained in the course
    1. Define the types Student and Class. For this purpose, consider that the information related to the students in a class is stored in a linked list of students.
    2. Define a function int addStudent(Class *t, Student a, FILE *f); that adds the information of a given student a to a class t, which is stored in a file f named "info_new_students.txt". The file follows the format: 
      
Ana Filipa Silva, 202105440, 19
Pedro Tomás, 202005823, 10
José Filipe Fernandes, 202105635, 15
      The implemented function should return 0 if the operation is successful and 1 otherwise.
    3. Define a function Student *search(Class t, int number); that searches for the student with a given number number in the class t.
      The function should return NULL if the student's information does not exist; otherwise, it should return the address where that information is stored.
    4. Define a function that determines how many students passed the course (i.e., those who obtained a final grade greater than or equal to 10). Write this information to a file named "approved.txt".
