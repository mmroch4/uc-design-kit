      Given a Connect Four board, determine whether the first player can win immediately or force a win on their second move — that is, reach a position where, regardless of what the second player does, the first player wins on the next turn.
    Read the problem statement carefully and try to submit an Accepted solution.
    Hint - Think recursively with backtracking

    - The problem has a natural game-tree structure: the first player chooses a column, the second responds, and then the first plays again. You can explore this tree recursively, trying all possible moves and checking whether there exists a sequence in which the first player wins.

    - The maximum depth is 3 (move A, move B, move A), so the tree is small.

    - To explore the game tree without copying the entire board at each move, use backtracking. This allows you to try all possibilities and revert the board to its original state after each attempt.

    - Don't forget to check after each move whether any player has 4 consecutive pieces (horizontal, vertical, or diagonal). It is enough to scan all cells and check the 4 possible directions from each one.

Exercise 2) Manipulation of Arrays

  1. [PI043] Eval
      Given an arithmetic expression with integers, additions (+) and multiplications (*), compute its result respecting operator precedence: multiplications are evaluated before additions.
    Read the problem statement carefully and try to submit an Accepted solution. Don't forget to test it first on your computer!
    Hint - Do not evaluate from left to right

    - If you simply evaluate from left to right, 5 + 2 * 3 would give (5 + 2) * 3 = 21 instead of 5 + (2 * 3) = 11. You must ensure that all multiplications are performed before additions!

    - A natural strategy is to do it in two steps: first multiply, then add. That is:

    1. First step: scan the expression and resolve all multiplications, grouping the products into "terms".
    2. Second step: sum all the terms.
    3. For example, 5 + 2 * 3 * 4 + 1 has three terms: 5, 2*3*4 = 24, and 1. The sum is 5 + 24 + 1 = 30.

    - Note: Don't forget any remaining elements or special cases (empty arrays)!

    Hint #2

    - With n numbers, the expression has 2n - 1 tokens in total (numbers and operators alternating). You can read everything into an array, storing the numbers as they are and the operators as values indicating + or * (for example, 0 for addition and 1 for multiplication).

    - To build the terms, you can traverse the token array. Keep an accumulator for the current term (start with the first number). Each time you encounter an operator:

    1. If it is *: multiply the accumulator by the next number.
    2. If it is +: store the accumulator as a complete term and start a new accumulator with the next number.

    - At the end, sum all the stored terms.

  2. Circular Rotation. Implement a program that simulates the circular rotation (to the right) of an array v of integers.
    The program should receive n integer values from the user and store them in v, and it should also receive a valid number of rotations r. The program should print the resulting array after performing the r rotations. Notes: rotating an array to the right circularly means that the first element moves to the second, and the last element moves to the first; you should only use simple data structures, i.e., arrays, and avoid using additional libraries.
    1. Start by developing an iterative algorithm, i.e., move the elements of the array one by one until performing the r rotations.
    2. The previous algorithm involves moving all the elements r times! Can you design a more efficient algorithm? Develop an algorithm that optimizes this process.

  4. Undo instruction. LIFO (Last In, First Out) is a data organization and processing strategy that is the opposite of FIFO.
