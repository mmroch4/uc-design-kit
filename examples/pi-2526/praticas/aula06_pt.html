Exercício 1) Strings no Mooshak

  1. [PI016] Signal in the Silence
      O objetivo deste exercício é descodificar uma mensagem transmitida em Morse binário.
    Nota importante sobre a codificação (informação que está na imagem do enunciado):
    • 1: representa um ponto (dot)
    • 111:representa um traço (dash)
    • 0: separa símbolos dentro de uma letra
    • 000: separa letras dentro de uma palavra
    • 0000000: separa palavras
    Por exemplo, a letra A em Morse é .-, que em binário fica 10111 (ponto> + separador + traço).
    Leia o enunciado do problema com atenção e tente enviar uma solução Accepted. Não se esqueça de testar primeiro no seu computador!

    Sugestão

    - O problema é essencialmente de parsing: tens de percorrer a string binária e identificar o que cada grupo de 0s e 1s representa. Pensa no problema em camadas:

    • Divida a string em palavras (separadas por 7 zeros).
    • Dentro de cada palavra, divida em letras (separadas por 3 zeros).
    • Dentro de cada letra, divida em símbolos (separados por 1 zero): um 1 é ponto, um 111 é traço.
    • Consulte a tabela Morse para converter cada sequência de pontos e traços no carácter correspondente.


    Sugestão #2

    - Em vez de analisar a string caracter a caracter e tentar perceber onde está, é mais simples percorrê-la contando grupos de caracteres iguais consecutivos.

    - Pode usar uma função auxiliar que avança o índice enquanto o caracter for o mesmo e devolve quantos encontrou:

    - Cuidado com o fim da string!



    Sugestão #3

    - Uma tabela Morse hardcoded pode dar jeito!

    - Uma forma prática em C é usar um array de strings indexado pelo código ASCII do carácter.

    - Para descodificar, basta percorrer os 36 caracteres possíveis e comparar a sequência de pontos e traços que construíu com data[c], usando a função strcmp.

  2. [PI018] Palindrome Fix
      Neste exercício pretende-se que verifique se uma string é um palíndromo e, se não for, calcular o número mínimo de alterações necessárias para a tornar um.
    Recorda que um palíndromo é uma string que se lê igual da esquerda para a direita e da direita para a esquerda. Por exemplo, "madam" é um palíndromo, mas "xoxo" não é.
    Leia o enunciado do problema com atenção e tente enviar uma solução Accepted.

    Sugestão

    - Um palíndromo tem de verificar s[i] == s[n-1-i] para todas as posições i.

    • Só precisas de verificar metade da string (i.e., a outra metade é simétrica).

    - Como pode calcular o mínimo de alterações para que se torne um palindrome?

    • Pense no que precisa de fazer sempre que encontra um par (s[i], s[n-1-i]) em que os caracteres são diferentes.
    • Precisas de mudar pelo menos um deles para tornar esse par simétrico, certo?
    • Tendo isto em mente o que pode concluir sobre o número mínimo de alterações?

Exercício 2) Recursão e Pesquisa

Recursões Simples

  1. A Profecia de Fibonacci. De acordo com uma antiga profecia, uma sequência de números contém a chave para desvendar tesouros escondidos.
    A sequência segue o padrão seguinte:
    • Os primeiros dois números são 0 e 1.
    • Cada número seguinte é a soma dos dois anteriores.
    Esta é conhecida como a Sequência de Fibonacci!

    Escreva uma função recursiva para encontrar o n-ésimo número de Fibonacci:
    int fibonacci(int n);

    Exemplos: 
    Input:  Qual é o valor de n? 6
Output: O 6º número de Fibonacci number é: 5

Input:  Qual é o valor de n? 13
Output: O 13º número de Fibonacci é: 144
  2. Palíndromos. Recorde que um palíndromo é uma palavra que se lê de igual forma para a frente e para trás.
    Escreva uma função recursiva que verifique se uma data palavra é um palíndromo:
    int isPalindrome(char str[], int start, int end);

    A função deve retornar 1 se a palavra for um palíndromo e 0 caso contrário.
    Exemplos:
    Input:  Escreva um palavra: level
Output: A palavra é um palíndromo!

Input:  Escreva um palavra: magic
Output: A palavra NÃO é um palíndromo.

Exercício 3) Conversão de Base Manual

Sistema Numérico e Conversão de Bases

Um sistema numérico é uma forma de representar e expressar números utilizando uma base específica. Cada sistema é caracterizado por uma base, que determina a quantidade de diferentes dígitos usados nesse sistema.

Em computação e matemática, os sistemas numéricos mais comuns são:

  • Decimal (Base 10): Utilizado no dia a dia, é composto por dígitos de 0 a 9.
  • Binário (Base 2): Utilizado em eletrónica digital e computação, é composto apenas pelos dígitos 0 e 1.
  • Octal (Base 8): Por vezes utilizado em computação, é composto por dígitos de 0 a 7.
  • Hexadecimal (Base 16): Comum em programação e endereçamento de memória, inclui os dígitos de 0 a 9 e as letras A-F (representando os valores de 10 a 15).

É frequentemente útil (ou necessário) converter um número n numa base b1 para outra base b2. Os métodos de conversão de bases podem ser definidos da seguinte forma:

  • Decimal para Binário: Dividir repetidamente por 2, registando os restos em ordem inversa.
  • Binário para Decimal: Multiplicar cada bit por 2 elevado ao seu índice de posição e somar os resultados.
  • Decimal para Hexadecimal: Dividir repetidamente por 16, registando os restos em ordem inversa.
  • Hexadecimal para Decimal: Multiplicar cada dígito por 16 elevado ao seu índice de posição e somar os resultados.
  • Binário para Hexadecimal: Agrupar os bits em conjuntos de quatro e converter cada grupo para o seu equivalente hexadecimal.

  5. O algoritmo para adição de dois inteiros positivos x e y, que se aprende no ensino básico, pode ser usado para somar x e y, representados em qualquer base b.


    Recorde que: começamos pelos dígitos menos significativos, adicionamo-los, e se o valor da soma exceder b-1, existirá um carry, de uma unidade ("e vai 1") , que será acrescentado ao próximo par.
    Ou seja, se x i + y i + carry > b - 1 , fica com x i + y i + carry - b na posição i do resultado e continua com carry = 1 ; se x i + y i + carry < = b - 1 , fica com x i + y i + carry na posição i e passa a ter carry = 0 . O valor inicial de carry é zero.

    1. Implementar uma função 
      void soma(char x[], char y[], int b, char res[]);

      para determinar a soma de dois inteiros não negativos x e y representados na base b, com b ∈ [2, 10] ∪ {16}.
      O resultado será colocado no array dado por res. Admita que reservou espaço suficiente.
      Recorde que se c tem o código de um algarismo, então o valor do algarismo é dado por c - '0'. Para a base 16, temos ainda 'A', 'B', ..., 'F', com valores 10, 11, . . . , 15, dados por c - 'A' + 10.
    2. Completar e testar o programa, onde valida se a cadeia de caracteres dada por x constitui uma representação válida para um inteiro na base indicada.
      Essa função retorna 1 se a representação for válida. Caso contrario, retorna 0.
  6. [PI020] License Plate
      As matrículas são emitidas por ordem alfabética: a, b, ..., z, aa, ab, ..., az, ba, ..., zz, aaa, ....
    Dada uma matrícula, determine quantas matrículas foram emitidas até essa (inclusive).
    Leia o enunciado do problema com atenção e tente enviar uma solução Accepted.

    Sugestão

    - Divide o problema em duas partes, tendo em conta que o total de matrículas emitidas até à matrícula s de comprimento n é:

    1. Todas as matrículas com comprimento menor que n, ou seja, todas as de 1 letra, todas as de 2 letras, etc.
    2. As matrículas de comprimento exactamente n que vêm antes ou são iguais a s.

    - Quantas matrículas existem com exactamente k letras? São todas as combinações de k letras minúsculas: 26k.

    • Para uma matrícula de comprimento n, a soma das matrículas mais curtas é 26 + 262 + ... + 26(n-1).

    - As matrículas de comprimento n estão ordenadas como se fossem números em base 26. Para saber a posição de s dentro das matrículas de comprimento n, basta converter a string para esse número, e como queres contar inclusive, somas 1 no final.

    - Lembre que pode usar s[i] - 'a' para obter o valor numérico de cada letra. A conversão da string para base 26 é análoga à conversão de uma string de dígitos para um número inteiro, que já deves conhecer.
