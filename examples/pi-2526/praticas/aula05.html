    • Count the number of occupied cells (with 'X' or 'O') while traversing the board.

    - The board is an N×N matrix of characters. You can read it row by row (i.e., as a string) using the function scanf("%s", ...).

    - Declare a two-dimensional char array with sufficient size to store each row (note: do not forget the '\0' character at the end of each string).

  9. Mooshak [PI013] Game of Life
      Read the problem statement and try to submit an Accepted solution. Don’t forget to test it on your computer first!
    Hints #1 - Thinking about the problem...

    - The game evolves in iterations.

    - In each iteration, the new state of all cells is calculated based on the current state — never on the new state being calculated.

    - A live cell dies if it has 0, 1, or 4+ alive neighbors; a dead cell becomes alive if it has exactly 3 alive neighbors.

    Hints #2

    - Start by reading the initial state of the matrix.

    - Begin a loop that iterates I times, and in each iteration calculate the next state and replace the current one.

    • Do not modify the matrix while you are still reading it to calculate the new values!
    • If you update the cell (i, j) before processing its neighbors, the neighbor calculations will be incorrect.
    • Can you find a solution to handle this?

    - At the end, print the final state.

    - Start by writing only the reading and printing, and verify they are correct before handling the iterations.

  5. Mooshak [PI014] The World of the Turtle
      Read the problem statement and try to submit an Accepted solution. Don’t forget to test it on your computer first!
    Hints

    - Save the state of the turtle.

    • The turtle has four attributes you need to save: position (x, y), current direction, and whether the pen is up or down.
    • Start at (0,0), facing East, with the pen up.

    - There are 4 directions: North, West, South, East.

    • You can store them as two displacement arrays:
    • int dx[4] = { 0, -1, 0, 1 }; // East, North, West, South
    • int dy[4] = { 1, 0, -1, 0 };
    • The current direction is an index di in these arrays. Turning left increments di, turning right decrements it.
    • Use modulo 4 to "wrap around".

    - When moving x steps, advance one step at a time in a loop. At each step, update the position and, if the pen is down, mark the cell with '*'. Be careful with the grid boundaries!

  6. Implement a function with the following declaration: 
    void truncW(char text[], int n);

    Given a string text composed by several words (words are separated by one or more spaces) and an integer n, the function truncates all words so that each word has at most n characters.
    Example: 
    char text[] = "university, faculty and fraternity"
truncW(text, 4);  // text becomes "univ facu and frat"
    Note that the word "and" has only 3 characters (3 < 4) and so it remains unaltered (i.e. it isn't truncated).
