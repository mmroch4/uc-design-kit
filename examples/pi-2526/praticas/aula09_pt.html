  3. [PI045] Connect Four in Two
      Dado um tabuleiro de Connect Four, determina se o primeiro jogador consegue ganhar imediatamente ou forçar uma vitória na sua segunda jogada — ou seja, colocar-se numa posição em que, independentemente do que o segundo jogador faça, o primeiro ganha no turno seguinte.
    Leia o enunciado do problema com atenção e tente enviar uma solução Accepted.

    Sugestão - Pense recursivamente com backtracking

    - O problema tem uma estrutura natural de árvore de jogo: o primeiro jogador escolhe uma coluna, o segundo responde, e o primeiro joga de novo. Pode explorar esta árvore recursivamente, tentando todas as jogadas possíveis e verificando se existe alguma sequência em que o primeiro jogador ganha.

    - A profundidade máxima é 3 (jogada A, jogada B, jogada A), por isso a árvore é pequena.

    - Para explorar a árvore de jogo sem precisar de copiar o tabuleiro inteiro a cada jogada, use backtracking. Isto possibilitará explorar todas as possibilidades e reverter o tabuleiro ao estado original após cada tentativa.

    - Não se esqueça de, após cada jogada, verificar se algum jogador tem 4 peças consecutivas (horizontal, vertical ou diagonal). Basta percorrer todas as células e verificar as 4 direcções possíveis a partir de cada uma.

Exercício 2) Manipulação de Arrays

  1. [PI043] Eval
      Dada uma expressão aritmética com inteiros, adições (+) e multiplicações (*), calcula o seu resultado respeitando a precedência de operadores: as multiplicações são calculadas antes das adições.
    Leia o enunciado do problema com atenção e tente enviar uma solução Accepted. Não se esqueça de testar primeiro no seu computador!

    Sugestão - Não calcules da esquerda para a direita

    - Se calcular simplesmente da esquerda para a direita, 5 + 2 * 3 daria (5 + 2) * 3 = 21 em vez de 5 + (2 * 3) = 11. Tem de garantir que todas as multiplicações são resolvidas antes das adições!

    - Um estratégia natural é fazer em dois passos: primeiro multiplicar, depois somar. Ou seja:

    1. Primeiro passo: percorra a expressão e resolve todas as multiplicações, agrupando os produtos em "termos".
    2. Segundo passo: soma todos os termos.
    3. Por exemplo, 5 + 2 * 3 * 4 + 1 tem três termos: 5, 2*3*4 = 24, e 1. A soma é 5 + 24 + 1 = 30.

    - Nota: Não se esqueça dos elementos restantes nem do caso especial (arrays vazios)!


    Sugestão #2

    - Com n números, a expressão tem 2n - 1 tokens no total (números e operadores alternados). Pode ler tudo para um array, guardando os números como estão e os operadores como um valor que indique + ou * (por exemplo, 0 para adição e 1 para multiplicação).

    - Para construir os termos pode percorrer o array de tokens. Mantenha um acumulador para o termo actual (começa com o primeiro número). Cada vez que encontra um operador:

    1. Se for *: multiplica o acumulador pelo número seguinte.
    2. Se for +: guarda o acumulador como um termo completo e começa um novo acumulador com o número seguinte.

    - No final, soma todos os termos guardados.

  2. Rotação Circular. Implemente um programa que simule a rotação circular (para a direita) de um vetor v de números inteiros.
    O programa deve receber do utilizador n valores inteiros e guarda-los em v e também deve receber um número de rotações válido r. O programa deve imprimir o vetor resultante depois de efetuadas as r rotações. Notas: rodar um vetor para a direita de forma circular significa que o primeiro elemento passa para segundo e o último elemento passa para primeiro; deve apenas usar estruturas de dados simples, ie. arrays, e não deve usar bibliotecas adicionais.
    1. Comece por desenvolver um algoritmo iterativo, ie. mova os elementos do vetor um a um até efetuar as r rotações.
    2. O algoritmo anterior implica mover todos os elementos r vezes! Consegue desenhar um algoritmo mais eficiente? Desenvolva um algoritmo que otimiza este processo.

    Exemplo: 
    Input:  n = 5
        v[] = [1, 2, 3, 4, 5]
        r = 2
Output: Vetor após 2 rotações: [4, 5, 1, 2, 3]
  3. Atendimentos. FIFO (First In, First Out), que em português significa "o primeiro a entrar é o primeiro a sair", é uma estratégia de organização e processamento de dados onde o primeiro item inserido é o primeiro a ser removido/processado. Uma fila está normalmente associada ao conceito FIFO, onde os dados entram por um lado (início) e saem pelo outro (fim). Tendo este conceito em mente, implemente um programa interativo para gerir uma fila de clientes para um serviço de atendimento ao público.
    O seu programa deve permitir as seguintes operações:
    • Adicionar um cliente ao fim da fila de clientes.
    • Atender o próximo cliente, isto significa remover o cliente que está na frente da fila. (Nota:Vamos ignorar atendimentos prioritários.)
    • Listar todos os clientes na fila a qualquer momento.
    • Encerrar o programa.
    Notas: Use apenas estruturas de dados simples para simular a fila, tais como arrays, e não use bibliotecas adicionais. A estrutura da fila deve ser circular, para isso controle as posições de início e fim da fila e o número de clientes em espera.

  4. Instrução Undo. LIFO (Last In, First Out), que em português significa "o último a entrar é o primeiro a sair", é uma estratégia de organização e processamento de dados que é o oposto do FIFO. Uma pilha está normalmente associada ao conceito LIFO, onde os dados entram um a seguir ao outro e são colocados sempre no final e só podem sair pelo mesmo lado que entram (ie., pelo fim). Tendo este conceito em mente, implemente um programa interativo para simular a instrução undo.
    Num editor de texto simple, sempre que um utilizador escreve uma palavra, ela é guardada numa pilha de ações. Se o utilizador quiser desfazer a última ação, a palavra no topo da pilha é removida (simulando o comando Undo).
    O seu programa deve permitir as seguintes operações:
    • Inserir uma palavra, de forma a simular a escrita num editor de texto.
    • Desfazer a última palavra, isto significa remover a palavra que está no topo da pilha.
    • Mostrar a palavra que está no topo da pilha (ie., última palavra escrita).
    • Encerrar o programa.
    Notas: Use apenas estruturas de dados simples para simular a pilha, tais como arrays, e não use bibliotecas adicionais. A estrutura da pilha deve ser tal que só é possível ter acesso ao último elemento introduzido na pilha, para isso controle a posição de fim da pilha e o número de palavras escritas.
