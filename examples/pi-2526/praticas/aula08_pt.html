Exercício 1) Mooshak

  1. [PI038] Merge Sorted Arrays
      Alice e Bob têm cada um um vector de notas ordenado por ordem crescente. A tua tarefa é juntá-los num único vector também ordenado, sem usar nenhuma função de ordenação já pronta.
    Leia o enunciado do problema com atenção e tente enviar uma solução Accepted. Não se esqueça de testar primeiro no seu computador!

    Sugestão - Não ordenes, funde

    - A abordagem ingénua seria juntar os dois arrays e ordenar o resultado. Mas há uma forma muito mais eficiente: como os dois arrays já estão ordenados, pode construir o resultado percorrendo-os simultaneamente, escolhendo sempre o menor elemento disponível entre os dois. Isto chama-se merge.

    - Pode usar 3 cursores, um por cada array (i para o da Alice, j para o do Bob) e um cursor k para a posição actual no array resultado. Em cada passo, compare os elementos apontados pelos dois cursores e copie o menor para o resultado, avançando o cursor correspondente.

    - Nota: Não se esqueça dos elementos restantes nem do caso especial (arrays vazios)!

  2. [PI039] Shifting Numbers
      A Joyce precisa de rodar um array de inteiros k posições para a direita (se k positivo) ou para a esquerda (se k negativo), de forma circular — os elementos que saem de um extremo reaparecem no outro.
    A sua tarefa é implementar a função 
    void shift(int a[], int n, int k);

    O código da função main e da função de impressão já são fornecidos — só tens de escrever a função shift.
    Leia o enunciado do problema com atenção e tente enviar uma solução Accepted.

    Sugestão

    - Para resolver o problema que tem em mão pense na seguinte pergunta: O que significa rodar k posições para a direita?

    - Rodar para a direita 1 posição significa que cada elemento na posição i passa para a posição i+1, e o último elemento vai para a posição 0.

    - Generalizado: o elemento que estava na posição i passa para a posição (i + k) % n.

    - Nota: Se tentar fazer a rotação directamente no array a, vai sobrescrever valores antes de os ter copiado. Pense nume forma fácil e rápida de resolver isso!


    Sugestão #2

    - O elemento que deve ir para a posição i após rodar k posições para a direita vinha da posição (i - k + n) % n. Colocar + n é necessário para garantir que o resultado do módulo não fica negativo quando k é positivo e i - k < 0.

    - E para k negativo? Para k negativo (rotação para a esquerda), a fórmula (i - k + n) % n continua a funcionar directamente — subtrair um k negativo é o mesmo que somar o seu valor absoluto. Não precisas de tratar este caso separadamente.

  3. [PI040] Josephus Flower
      Tens n pétalas numeradas de 1 a n dispostas em círculo. Percorres as pétalas alternando entre "ficar" e "remover", voltando ao início sempre que necessário, até restar apenas uma. Determina qual é a pétala que sobra.
    Leia o enunciado do problema com atenção e tente enviar uma solução Accepted. Tente resolver este problema sem sugestões!

Exercício 2) Base de Dados de Equipas, Jogadores e Torneios de eSports

Dada uma base de dados com informação sobre jogadores, equipas e torneios de eSports, pretende-se consultar a mesma para obter várias informações. As estruturas de dados que vão ser usadas pelo programa obedecem à seguinte especificação:

No exemplo, World eSports é o torneio 0 e Elite Battle o torneio 2. Os torneios em que um jogador está inscrito para participar são identificados pelos seus números de ordem no array Torneios. Da mesma forma, os jogadores que pertencem a uma equipa são identificados pelos seus números de ordem no array Jogadores. O identificador id de um jogador é uma sequência de 7 caracteres (o primeiro é a letra J seguido de 6 dígitos).

  1. Escreva uma função 
    void procuraJogador(char *palavranome);

    para imprimir o código e nome dos alunos cujo nome contém uma palavra dada por palavranome.
    Por exemplo, se a palavra fosse "Silva", deveria imprimir:
    Jogadores cujo nome inclui "Silva":
J012345 Andreia Silva
J067890 Marco Silva

    Não deverá ser feita qualquer ordenação dos dados. A menos que a ordenação seja explicitamente solicitada, no output deverá ser mantida a ordem de ocorrência dos dados nas estruturas de dados.
  2. Escreva uma função 
    int id2Jogador(char *id, char *nome);

    que escreve na cadeia de carateres nome o nome do jogador correspondente ao identificador id (a função retorna 0 se não existir, e 1 caso contrário).
  3. Escreva uma função 
    int jogadoresDaEquipa(char *nomeEquipa);

    que imprime na saída padrão a lista de nomes dos jogadores de uma determinada equipa, sendo dado o nome da equipa como parâmetro da função, e retorna o número total de jogadores da equipa.
  4. Escreva uma função 
    int jogadoresNoTorneio(char *nomeTorneio, int *indices);

    que guarda no array indices os índices (das posições em Jogadores>) dos jogadores que participaram num determinado torneio, dando o nome do torneio. Retorna o número de jogadores nessas condições.
  5. Escreva uma função 
    int mediaTorneiosPorJogador();

    que retorna o número médio de torneios em que os jogadores participaram.
  6. Escreva uma função 
    int jogadoresMaisAtivos(int *indices);

    que guarda no array indices os índices das posições (em Jogadores) dos jogadores que participaram em mais torneios do que a média. Retorna o total desses jogadores.
  7. Escreva uma função 
    int maxTorneiosPorAno(int ano);

    que retorna o número máximo de torneios em que um jogador participou num dado ano.
  8. Escreva uma função 
    int torneiosDoJogadorAno(int posJogador, int ano);

    que retorna o número de torneios de um dado ano em que um jogador participou.
    Assume-se que posJogador contém o índice da posição do jogador em Jogadores, sendo uma posição válida.
  9. Escreva uma função 
    int participouEmVariosAnos(int posJogador);

    que verifica se um jogador participou em torneios de vários anos. Retorna um valor diferentes de 0 em caso afirmativo e 0 caso contrário.
    Assume-se que posJogador contém o índice da posição do jogador em Jogadores, sendo uma posição válida.
