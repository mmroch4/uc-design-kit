Exercise 1) Methods for Linked Lists

For the following exercises, consider the following data structure to represent linked lists of integer values, based on the structure presented in the theoretical lectures:

  1. Write a function 
    int size(LinkedList *list);

    that calculates the length of a linked list.
  2. Write a function 
    int removeEquals(LinkedList *list, int value);

    that removes all occurrences of a given integer value value from the list list.
    The function should return the number of elements removed from the list (i.e., the number of occurrences of value).
  3. Write a function 
    void free(LinkedList *list);

    that frees the memory occupied by a linked list.
  4. Write a function 
    void concatList(LinkedList *listA, LinkedList *listB);

    that appends the contents of list listB to list listA.
  5. Write a function 
    Node *invertList(LinkedList *list);

    that inverts the list list (without creating a new list).
    The function should return the new first element of the list.
  6. Write a function 
    void insertOrd(LinkedList *list, int value);

    that inserts a new element value into the list list in sorted order. Assume that the list list is already sorted.
  7. Write a function 
    void printSort(Node *first);

    that receives as argument the first element of an unsorted linked list and prints the values contained in the list in ascending order.
    Hint

    - you may use an array of pointers to store pointers to the nodes (elements) of the linked list, and then apply a sorting algorithm (e.g., qsort()) to the array.

    - However, be careful: in this case, the values to compare during the sorting are the data fields of the nodes pointed to by the pointers in the array.

Exercise 2) Book Management

Based on the LinkedList data structure and the functions developed in Exercise 1, write a program to manage the book records of a library. For each book, the library stores the following information: a unique identifier (an integer value), title (a string), author’s name (a string), year of publication (an integer value), and acquisition date (a structure containing day, month, and year information).

Your task is to use a linked list to store the data related to the books in the library, as well as to manage the flow of books that enter and leave the library.
To do this, you must answer the following questions by adding new methods or modifying the methods developed in Exercise 1 in order to add new books, (possibly) remove others, search for a specific identifier, or at least print sets of books.

Note: Make the necessary changes to the structures defined in the previous exercise so that each node (element) of the linked list contains the information of the corresponding book. You may use the following data structure to define this information.


As a starting point, you may use the code skeleton provided below and complete the missing parts. Alternatively, you may create your own code from scratch.
  1. Develop a function that adds a new book new_book to the list of books list. The function should add the book to the end of the list. The book information must be provided through standard input, with the following fields on separate lines: ID, Title, Author, Year of Publication, and Acquisition Date. 
    void add_new_book(LinkedList *list, Book new_book);
  2. Develop a function that prints to standard output the data of a given book, given its ID (id). If the book does not exist, the function should print an appropriate message. 
    void print_by_id(LinkedList *list, int id);
  3. Develop a function that prints all books by a given author whose name contains the name provided by the user (name). 
    void print_by_author(LinkedList *list, char *name);
    Hint

    - use the strstr() function from the string.h library to search for a substring within a larger string.

  4. Develop a function that prints all the books in the library sorted by title (alphabetical order). 
    void printSortByTitle(Node *first);
    Hint

    - use an array of pointers and the function qsort() together with strcmp().

  5. Develop a function to delete all books whose acquisition date is earlier than the year given as input to the function. The function should return the number of books deleted or print an appropriate message if no books meet these conditions. 
    int remove_by_year(LinkedList *list, int year);
