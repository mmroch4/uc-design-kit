Exercise 1) Manipulating Arrays

Before starting the exercises, test the following code examples from the theoretical lesson on arrays. Make sure you compile, run and understand what is happening.

  • write_binary.c - simple usage of an array to write binary digits
  • check_rep_digits.c - simple usage of an array to check repeated digits

Now let’s solve some problems that involve manipulating arrays.
Solve both the Mooshak problems and the extra problems from this exercise sheet.

  1. The goal os this exercise is to count, in a sequence of read integer values (all of them between 0 and 150), the number of values in the ranges 0 and 5, the number of values in the ranges 5 and 10, ..., the number of values in the ranges 145 and 150 (where the lower bound is excluded and the upper bound is included). Write a program that prints these counts.
    Hints

    - use an array of counters c[0], c[1], ..., c[29], where c[i] counts the values of x such that 5*i < x <= 5*(i+1).

  2. [PI006] Satellite Distance
      Read the problem statement and try to submit an Accepted solution. Don’t forget to test it on your computer first!

    Hints

    - read the two arrays.

    - iterate through both at the same time (same index i).

    - compute the absolute difference between a[i] and b[i].

    - store the smallest value you find.

    Note: For the absolute difference in C, you can use the function abs() from the stdlib.h library.

  3. Write a function that, given a set of integer values, returns how many of these values are strictly greater than a value provided by the user. The function should have the following prototype: 
    int count_biggers(int arr[], int size, int val);

    The function's arguments are an indexed variable arr with size size and a value val. The return value should be the count of elements in arr that are strictly greater than val.
    Example:
    int a[10] = {2, -3, 5, 10, 9, 88, -5, 8, 5, 2};
count = count_biggers(a, 10, 2);    // the function should return 6
  4. Define a function with the following prototype: 
    void range(int arr[], unsigned size, int start, int incr);

    The function should initialize the first size elements of an array arr with the values start, start + incr, start + 2*incr, ..., following an arithmetic progression with an initial term start and a common difference incr.
    Example:
    int a[5];
range(a, 5, 3, 2);    // a[] will contain {3, 5, 7, 9, 11}
  5. [PI008] Hiking Day
      Read the problem statement and try to submit an Accepted solution. Don’t forget to test it on your computer first!

    Hints

    - read the array.

    - calculate |a[i] - a[i-1]| for all i (including the link a[n-1] -> a[0]).

    - find the index where this difference is maximum.

    - print the array starting from the element after that index, going around circularly. To do this, you can start from index k, and use i % n to "wrap around".

  6. [PI009] Pascal Line
      Read the problem statement and try to submit an Accepted solution. Don’t forget to test it on your computer first!

    Hints

    - Pascal's triangle has a simple property: each element is the sum of the two elements directly above it.

    - Row 1 is just 1.

    - Each subsequent row is built from the previous one.

  7. Write a program that generates and prints an inverted identity matrix of order n. The inverted identity matrix is obtained by mirroring the traditional identity matrix along its central row. The program should prompt the user for a positive integer n (the matrix dimension) and then print the resulting matrix.
    Example: 
    Input: What is the dimension of the matrix?
       5

Output: Inverted Identity Matrix:
        0 0 0 0 1  
        0 0 0 1 0  
        0 0 1 0 0  
        0 1 0 0 0  
        1 0 0 0 0
    The program should ensure that n is a valid number and display an error message if not.
  8. A magic square is a square matrix of integers in which all rows, columns, and diagonals sum to the same value. In the following example, each row, column, and diagonal sums to the same value (15 in this case): 
    2  7  6
9  5  1
4  3  8
    Write a function 
    int magic(int a[20][20], int n);

    that checks whether a matrix is a magic square.
    The matrix is represented by an indexed variable a with a declared size of 20×20; the argument n specifies the sub-matrix to consider: for example, if n = 3 we should check whether the 3×3 sub-matrix containing the values from the first 3 rows and 3 columns is a magic square (ignoring the rest of the matrix).
    The function should return an integer: 1 if it is a magic square and 0 otherwise.
  9. Write a program that first reads the size N of a square matrix a[N][N], then reads all integers values of the matrix, row by row, and then calculates and outputs the same matrix rotated 90 degrees right.
    Sugestion: use an auxiliar matrix to determine the rotated matrix.
    Example: 
    Input:  3
        1 2 3
        1 2 3
        1 2 3

Output: 
        1 1 1
        2 2 2
        3 3 3
  10. In a class of 25 students, what is the probability that at least two of them share the same birthday? And if there are 50 students? The birthday paradox is the observation that this probability is higher than common intuition suggests.
    Write a program to estimate experimentally the probability of shared birthdays among n students by repeatedly generating random days (n values between 1 and 365) and checking for duplicates.
    Use the rand() function from the C standard library stdlib.h to generate a random array of n days and write a helper function to check for duplicates.
    By performing a large number of experiments, the relative frequency of duplicate occurrences provides an approximate probability.
    The number of students n and the number of experiments should be easily modifiable (for example, using macros).

Exercise 2) Working with Strings

Now test the following code example from the theoretical lesson on string manipulation. Make sure you compile, run and understand what is happening.

  • reverse_string.c - simple program that reverses a string

Now you can use the previous example to solve and test the following problems, which involve implementing helper functions to work with strings.

  1. In the previous class, you were challenged to write a program that converts a sentence read from standard input to uppercase. In this class, you should rewrite your program to include the definition of a helper function 
    void capitalize(char str[]);

    which convert all letters in a given string to uppercase, leaving other characters unchanged.
    Note that the function's argument is a sequence of characters (not necessarily letters) terminated by '\0'.
  2. Write a function 
    int palindrome(char str[]);

    that checks whether a string is a palindrome, that is, if it reads the same from left to right and right to left.
    The function should return 1 if the string is a palindrome and 0 otherwise.
    Examples: 
    Input:  Arara
Output: 1

Input:  Praia
Output: 0

Input:  taco cat
Output: 1
  3. Write a function 
    int strong(char str[]);

    that checks whether a string is a "strong password" using the following criteria:
    • It must have at least 6 characters;
    • It must contain at least one uppercase letter, one lowercase letter, and one digit.
    The function should return 1 if both criteria are met and 0 otherwise. Hint: Define a helper function to count the number of characters in a string and additional helper functions to check whether a string contains at least one uppercase letter, one lowercase letter, and at least one digit.
    Examples: 
    Input:  Abr4cadabra
Output: 1

Input:  Apric0t
Output: 1

Input:  Ub40
Output: 0

Input:  POLICE
Output: 0
  4. Write a function 
    int decimal(char str[]);

    that, given a string containing only digits (i.e., '0', '1', ... , '9') and the null terminator '\0', representing a non-negative integer in decimal (i.e., base 10), returns the integer value of that number.
    Example:
    decimal("1234");
1234  // returns the integer 1234
  5. Write a function 
    void eliminate(char str[], char ch);

    that removes the first occurrence of a character ch from a string str. Note: Ensure that the null terminator '\0'is placed correctly.

  6. Write a program that includes the following helper functions for working with strings. Each function should perform the specified task:
    • Determine the longest word in a string.
    • Modify a string by replacing all occurrences of a character ch1 with another given character ch2.
    • Modify a string by replacing all occurrences of a substring sstr1 with another given substring sstr2.
    • Replace the first letter of each word in a string with its uppercase equivalent. Note that the first letter may not be the first character.
    Assume that a string is represented by a character array terminated by the null character ('\0').
