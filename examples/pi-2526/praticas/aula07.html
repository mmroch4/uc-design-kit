  2. The Mysterious Staircase. A traveler is climbing a staircase with n steps. They can climb either 1 step or 2 steps at a time. How many different ways can they reach the top?
    Write a recursive function that computes the number of ways to reach the top of a staircase with n steps:
    int countWays(int n);
    • Base cases:
      • If n = 0, return 1 (1 way to stay at the ground).
      • If n < 0, return 0 (no way to reach negative steps).
    • Recursive case:
      • countWays(n) = countWays(n-1) + countWays(n-2)
    Example:
    Input:  Enter number of steps: 4
Output: Ways to climb: 5

  4. [PI028] Permutations
      Given an integer n, print all permutations of the numbers from 1 to n, each on its own line, in increasing lexicographic order.
    Read the problem statement carefully and try to submit an Accepted solution.
    Hints

    - A permutation of n elements is built by choosing an element for the first position, and then filling the remaining n-1 positions with the remaining elements. This suggests a recursive approach.

    - You can implement a function solve(x) that decides which element to place at position x, and then calls solve(x+1) for the next positions.

    - The base case is x == n: the permutation is complete, so you can print it.

    - Note: Lexicographic order is automatically ensured if, at each position, you try elements in increasing order (from 1 to n). Since you always iterate from smallest to largest, the generated permutations are naturally sorted.

    - Attention: You need to keep track of which elements have already been used in previous positions, to avoid repeating them.

    • A simple way is to maintain an array visited[n], where visited[i] = 1 means that element i has already been used in the current permutation.
    • The step of unmarking (visited[i] = 0) is essential; this is called backtracking and allows reuse of the element in other permutations.

  1. Struct Point

    Consider the following structure presented in the theoretical classes, which represents the points in ℝ 2 (in the plane):

    Write a program that follows the instructions below.

    1. Write a function that calculates the Euclidean distance between two points.
      double distance(Point a, Point b);
    2. Write a function that returns 1 if two points are equal, and returns 0 otherwise. 
      int same_point(Point a, Point b);
      Note: Since the points are defined using floating-point numbers with finite precision, two points are considered equal if the Euclidean distance between them is less than 0.000001.
    3. Write a program that reads a list of 10 points from standard input (given by the values x and y) and prints to standard output the pair of points with the greatest distance between them.

      double rect_area(Rect r);
    6. Write a function that returns 1 if the point p is inside the rectangle r, and returns 0 otherwise.

  3. [PI029] The Tax Collector
      Now that you have practiced with structures, read the statement of problem PI029 and try to submit an Accepted solution.
    Hint

    - Each company has 5 fields, each on a separate line. Note that the company name and the activity area are strings that may contain spaces — therefore, you cannot use scanf("%s", ...) to read them. Use fgets or read character by character until the end of the line.

    - The activity code is an integer between 1 and 100. This allows using an array act[101] initialized to zero, where act[i] accumulates the total revenue of all companies with code i.

    - For flag == 0, simply count how many positions in the array are non-zero.

    - For flag == 1, the statement asks for results in ascending order of code. Since the array act is indexed by the code itself, just iterate from 1 to 100 and print the non-zero entries; the order is already ascending automatically.

    - Use a struct to organize the information of each company!

  4. [PI030] University Access Statistics
      Read the problem statement and try to submit an Accepted solution.
    Hint

    - You need two arrays:

    • One with all the applicants (needed for flag == 1, where you must print them in the order they were read).
    • One with the schools, indexed by code (1 to 300), where you accumulate the number of applicants and the sum of scores.

    - Each applicant has 5 lines: an integer, a string, a string, an integer, and an integer. The problem is that after reading an integer with scanf, the \n remains in the buffer, and the next string read catches an empty line. You must consume that \n before reading the string.

    - Since the school code is an integer between 1 and 300, you can use that value directly as the index of the schools array.
