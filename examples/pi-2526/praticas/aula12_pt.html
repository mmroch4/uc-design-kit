Caso encontrem dificuldades, falem com os docentes e outros colegas para obterem sugestões de como abordar um determinado problema, mas façam um esforço genuino para depois codificarem e porem a funcionar a vossa solução. Esta é a melhor forma de ficarem competentes na resolução destes problemas (ou seja aprenderem) e habituados a ultrapassar as dificuldades que possam surgir. No entanto, qualquer ajuda mais direta que tenham recebido de outros colegas deve ser reconhecida nos comentários do programa que submetem.

Para um problema contar tem de acertar todos os testes (ou seja, ter accepted). Mesmo que resolva todos os problemas, o máximo numa aula é de 100%.

Exercício 1) Árvores Binárias

Para os exercícios seguintes, considere as estruturas de dados utilizadas nas aulas teóricas para representar árvores binárias de valores inteiros:


Pode assumir que as seguintes funções auxiliares já estão disponíveis (consulte a aula teórica aqui):


  1. Escreva uma função
    int height(BTree *t);

    que devolve a altura da árvore. A altura de uma árvore é o comprimento do caminho mais longo entre a raiz e uma folha. A altura de uma árvore vazia é -1; a altura de uma árvore com um único nó é 0.
  2. Escreva uma função
    int countLeaves(BTree *t);

    que conta o número de folhas (isto é, o número de nós sem filhos).
  3. Escreva uma função
    int isSymmetric(BTree *t);

    que devolve 1 se a árvore for simétrica, ou 0 caso contrário. Uma árvore é considerada simétrica se as suas subárvores esquerda e direita forem imagens espelhadas uma da outra. Por exemplo, uma árvore cuja raiz tem valor 1, filho esquerdo 2 e filho direito 2, em que o filho esquerdo tem um filho direito 3 e o filho direito tem um filho esquerdo 3, é simétrica.
    Dica

    - Escreva uma função auxiliar isMirror(BTNode *a, BTNode *b) que verifica se duas subárvores são imagens espelhadas uma da outra: são espelhadas se ambas estiverem vazias, ou se ambas tiverem o mesmo valor e a->left for o espelho de b->right e a->right for o espelho de b->left.

  4. Escreva uma função
    int maxValue(BTree *t);

    que devolve o valor máximo armazenado numa árvore binária não vazia (não necessariamente uma árvore binária de pesquisa). Pode utilizar INT_MIN de limits.h como valor inicial para a comparação.
  5. Escreva uma função
    int isBalanced(BTree *t);

    que devolve 1 se a árvore for equilibrada, significando que, para cada nó, as alturas das suas subárvores esquerda e direita diferem em no máximo 1, ou 0 caso contrário.
    Sugestão

    - Uma solução ingénua chama height e isBalanced separadamente em cada nó, visitando os nós várias vezes.

    - Para uma solução mais eficiente, escreva uma função auxiliar que devolva a altura de uma subárvore se esta estiver equilibrada, ou -2 como valor sentinela caso seja detetado algum desequilíbrio, permitindo interromper a recursão antecipadamente.

  6. Um caminho da raiz até uma folha é uma sequência de nós que começa na raiz e termina numa folha, seguindo arestas entre pai e filho.
    Escreva uma função
    int pathSum(BTree *t, int target);

    que devolve 1 se existir um caminho da raiz até uma folha cuja soma dos valores dos nós seja igual a target, ou 0 caso contrário.
    Sugestão

    - Em cada chamada recursiva, subtraia o valor do nó atual ao target. Quando chegar a uma folha, verifique se o valor restante de target é zero.

  7. Escreva uma função
    int depth(BTree *t, NodeInfo val);

    que devolve a profundidade do nó com valor val (o comprimento do caminho entre a raiz e esse nó), ou -1 caso o valor não esteja presente na árvore.

    Para os exercícios seguintes, assuma que as árvores são BSTs válidas, ordenadas segundo a regra apresentada nas aulas: cada nó é maior do que todos os valores da sua subárvore esquerda e menor do que todos os valores da sua subárvore direita.

  8. Escreva uma função
    int isBST(BTree *t);

    que devolve 1 se a árvore respeitar a propriedade de BST em todos os nós, ou 0 caso contrário.
    Sugestão

    - Verificar apenas os filhos imediatos de cada nó não é suficiente. Utilize uma função auxiliar que propague limites mínimos e máximos permitidos ao longo da recursão. Pode usar INT_MIN e INT_MAX de limits.h como limites iniciais.

  9. Escreva uma função
    NodeInfo minBST(BTree *t);

    que devolve o valor mínimo armazenado numa BST não vazia sem percorrer a árvore inteira.
    Dica

    - Numa BST, o valor mínimo encontra-se sempre no nó mais à esquerda. Continue a seguir o filho esquerdo até chegar a um nó sem filho esquerdo.

  10. Escreva uma função
    BTNode *deleteBST(BTNode *r, int val);

    que remove o nó com valor val da BST com raiz em r e devolve a nova raiz da subárvore. A propriedade da BST deve ser mantida após a remoção. Considere os três casos habituais: (a) o nó a remover é uma folha; (b) tem um filho; (c) tem dois filhos.
    Dica

    - Para o caso (c), substitua o valor do nó pelo do seu sucessor em ordem (o valor mínimo da subárvore direita) e, em seguida, remova esse sucessor em ordem da subárvore direita. Pode reutilizar minBST.
