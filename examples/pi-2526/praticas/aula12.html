Exercício 1) Binary Trees

For the following exercises, consider the data structures used in the theoretical lectures to represent binary trees of integer values:


You may assume the following helper functions are already available (consult the theoretical class here):


  1. Write a function
    int height(BTree *t);

    that returns the height of the tree. The tree height is the length of the longest path from the root to a leaf. The height of an empty tree is -1; the height of a tree with a single node is 0.
  2. Write a function
    int countLeaves(BTree *t);

    that counts the number of leaf nodes (that is, the number of nodes with no children).
  3. Write a function
    int isSymmetric(BTree *t);

    that returns 1 if the tree is symmetric, or 0 otherwise. A tree is said symmetric if its left and right subtrees are mirror images of each other. For example, a tree whose root has value 1, left child 2 and right child 2, where the left child has a right child 3 and the right child has a left child 3, is symmetric.
    Hint

    - Write an auxiliary function isMirror(BTNode *a, BTNode *b) that checks whether two subtrees are mirrors of each other: they are mirrors if both are empty, or if both have the same value and a->left mirrors b->right and a->right mirrors b->left.

  4. Write a function
    int maxValue(BTree *t);

    that returns the maximum value stored in a non-empty binary tree (not necessarily a BST). You may use INT_MIN from limits.h as a starting value for the comparison.
  5. Write a function
    int isBalanced(BTree *t);

    that returns 1 if the tree is balanced, meaning that for every node, the heights of its left and right subtrees differ by at most 1, or 0 otherwise.
    Hint

    - A naive solution calls height and isBalanced separately at each node, visiting nodes multiple times.

    - For a more efficient solution, write an auxiliary function that returns the height of a subtree if it is balanced, or -2 as a sentinel value if any imbalance is detected, allowing you to short-circuit the recursion early.

  6. A root-to-leaf path is a sequence of nodes starting at the root and ending at a leaf, following parent–child edges.
    Write a function
    int pathSum(BTree *t, int target);

    that returns 1 if there exists a root-to-leaf path whose node values sum to target, or 0 otherwise.
    Hint

    - At each recursive call, subtract the current node's value from the target. When you reach a leaf, check whether the remaining target is zero.

  7. Write a function
    int depth(BTree *t, NodeInfo val);

    that returns the depth of the node with value val (the length of the path from the root to that node), or -1 if the value is not present in the tree.

    For the following exercises, assume the trees are valid BSTs ordered by the rule presented in the lectures: every node is greater than all values in its left subtree and smaller than all values in its right subtree.

  8. Write a function
    int isBST(BTree *t);

    that returns 1 if the tree satisfies the BST property for all nodes, or 0 otherwise.
    Hint

    - Checking only the immediate children of each node is not sufficient. Use an auxiliary function that propagates allowed minimum and maximum bounds through the recursion. You may use INT_MIN and INT_MAX from limits.h as the initial bounds.

  9. Write a function
    NodeInfo minBST(BTree *t);

    that returns the minimum value stored in a non-empty BST without traversing the whole tree.
    Hint

    - In a BST, the minimum is always at the leftmost node. Keep going left until you reach a node with no left child.

  10. Write a function
    BTNode *deleteBST(BTNode *r, int val);

    that removes the node with value val from the BST rooted at r and returns the new root of the subtree. The BST property must be maintained after deletion. Handle the three standard cases: (a) the node to delete is a leaf; (b) it has one child; (c) it has two children.
    Hint

    - For case (c), replace the node's value with that of its in-order successor (the minimum value in the right subtree), then delete the in-order successor from the right subtree. You may reuse minBST.
