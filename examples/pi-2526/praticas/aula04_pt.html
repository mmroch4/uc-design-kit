  1. Pretende-se contar numa sequência de valores lidos, todos eles compreendidos entre 0 e 150, o número de valores entre 0 e 5, o número de valores entre 5 e 10, ..., o número de valores entre 145 e 150 (o limite inferior é excluído e o limite superior é incluído). Escreva um programa que imprima essas quantidades.
    Sugestão

    - use um array de contadores c[0], c[1], ..., c[29], em que c[i] conta os valores de x tais que 5*i < x <= 5*(i+1).

  2. Mooshak [PI006] Distância do Satélite
      Leia o enunciado do problema e tente enviar uma solução Accepted. Não se esqueça de testar primeiro no seu computador!
    Sugestão

    - lê os dois arrays.

    - percorre os dois ao mesmo tempo (mesmo índice i).

    - calcula a diferença absoluta entre a[i] e b[i].

    - guarda o menor valor que encontrares.

    Nota: Para a diferença absoluta em C, podes usar a função abs() da biblioteca stdlib.h.

  3. Escreva uma função que dado um conjunto de valores inteiros retorne quantos desses valores são estritamente maiores do que um valor dado pelo utilizador. A função deve ter a seguinte declaração de protótipo: 
    int count_biggers(int arr[], int size, int val);

    Os argumentos da função são uma variável indexada arr com tamanho size e um valor val e o valor de retorno deve ser a contagem do número de elementos de arr que são estritamente maiores do que o valor val.
    Exemplo:
    int a[10] = {2, -3, 5, 10, 9, 88, -5, 8, 5, 2};
count = count_biggers(a, 10, 2);    // a função deve retornar 6
  4. Defina uma função com a seguinte declaração de protótipo: 
    void range(int arr[], unsigned size, int start, int incr);

    A função deve inicializar os primeiros size elementos de um array arr com os valores start, start + incr, start + 2*incr, ..., isto é, segundo uma progressão aritmética, com termo inicial start e razão incr.
    Exemplo:
    int a[5];
range(a, 5, 3, 2);    // a[] passa a conter {3, 5, 7, 9, 11}
  5. Mooshak [PI008] Dia de Caminhada
      Leia o enunciado do problema e tente enviar uma solução Accepted. Não se esqueça de testar primeiro no seu computador!
    Sugestão

    - lê o array.

    - calcula |a[i] - a[i-1]| para todos os i (incluindo a ligação a[n-1] -> a[0]).

    - encontra o índice onde essa diferença é máxima.

    - imprime o array a partir do elemento seguinte a esse índice, dando a volta circular. Para isso pode começar a partir do índice k, podes usar i % n para "dar a volta".

  6. Mooshak [PI009] Linha de Pascal
      Leia o enunciado do problema e tente enviar uma solução Accepted. Não se esqueça de testar primeiro no seu computador!
    Sugestão

    - O triângulo de Pascal tem uma propriedade simples: cada elemento é a soma dos dois elementos diretamente acima dele.

    - A linha 1 é apenas 1.

    - Cada linha seguinte é construída a partir da anterior.

  7. Escreva um programa que gere e imprima uma matriz identidade invertida de ordem n. A matriz identidade invertida é obtida ao espelhar a matriz identidade tradicional na sua linha central. O programa deve receber do utilizador um número inteiro positivo n (dimensão da matriz) e, em seguida, imprimir a matriz resultante.
    Exemplo: 
    Input: Qual a dimensão da matriz?
       5

Output: Matriz Identidade Invertida:
        0 0 0 0 1  
        0 0 0 1 0  
        0 0 1 0 0  
        0 1 0 0 0  
        1 0 0 0 0
    O programa deve garantir que n seja um número válido e exibir uma mensagem de erro caso contrário.
  8. Um quadrado mágico é uma matrix quadrada de números inteiros tal que todas as linhas, colunas e diagonais somam o mesmo valor. No exemplo seguinte cada linha, coluna e diagonal soma o mesmo valor (15 neste caso): 
    2  7  6
9  5  1
4  3  8
    Escreva uma função 
    int magic(int a[20][20], int n);

    que testa se uma matrix é uma quadrado mágico.
    A matriz é representada por uma variável indexada a com dimensão declarada 20×20; o argumento n indica qual sub-matrix a considerar: por exemplo, se n = 3 devemos testar se a sub-matriz 3×3 que contém os valores das primeiras 3 linhas e 3 colunas é um quadrado mágico (e ignorar o resto da matriz).
    O resultado deve ser um inteiro: 1 se é um quadrado mágico e 0 caso contrário.
  9. Escreva um programa que leia a dimensão N de uma matriz quadrada, a[N][N], depois leia por linha os valores inteiros da matriz, e depois determine e escreva para o output a matriz que resulta de uma rotação de 90 graus para a direita Sugestão: use uma matriz auxiliar para determinar a rotação.
    Exemplo: 
    Input:  3
        1 2 3
        1 2 3
        1 2 3

Output: 
        1 1 1
        2 2 2
        3 3 3
  10. Numa turma com 25 alunos, qual é a probabilidade de que o aniversário de pelo menos dois deles seja no mesmo dia? E se forem 50 alunos? O paradoxo do aniversário é a constatação de que esta probabilidade é maior do que parece ao senso comum.
    Escreva um programa capaz de estimar experimentalmente a probabilidade de aniversários repetidos com n alunos escrevendo um programa que repetidamente gere dias aleatoriamente (n valores de 1 a 365) e verifique a ocorrência de repetições.
    Utilize a função rand() da biblioteca standard do C stdlib.h para gerar aleatoriamente um vector com n dias e escreva uma função auxiliar para testar repetições.
    Se fizer um grande número de experiências, a frequência relativa de ocorrência de repetidos dá um valor aproximado da probabilidade.
    O número de alunos n e de experiências deve ser facilmente modificável (por exemplo, usando macros).

Agora pode aproveitar o exemplo anterior para resolver e testar os problemas seguintes que envolvem implementação de funções auxiliares para trabalhar com strings.

  1. Na aula passada foi desafiado a escrever um programa convertesse para maiúsculas uma frase lida do standard input. Nesta aula pretendemos que reescreva o seu programa para incluir a definição de uma função auxiliar 
    void capitalize(char str[]);

    que transforma todas as letras de uma string lida em maiúsculas; os outros caracteres devem ficar inalterados.
    Note que o argumento da sua função é uma sequência de caracteres (não necessariamente letras) terminada por '\0'.
  2. Escreva uma função 
    int palindrome(char str[]);

    que testa se uma string é um palíndromo, isto é, se a string é igual quando lida da esquerda para a direita ou da direita para a esquerda.
    A função deve retornar 1 caso a string seja um palíndromo, e 0 caso contrário.
    Exemplos: 
    Input:  Arara
Output: 1

Input:  Praia
Output: 0

Input:  taco cat
Output: 1
  3. Escreva uma função 
    int strong(char str[]);

    que verifica se uma string é uma "password forte" usando o seguinte critério:
    • Deve ter pelo menos 6 caracteres;
    • Deve conter pelo menos uma letra maiúscula, uma letra minúscula e um algarismo.
    O resultado da função deve ser 1 se ambos os critérios se verificam e 0 caso contrário. Sugestão: Defina uma função auxiliar para contar o número de caracteres em um string e outras funções auxiliares para verificar se uma dada string contém pelo menos uma letra maiúscula e uma minúscula, e se contem pelo menos um digito.
    Exemplos: 
    Input:  Abr4cadabra
Output: 1

Input:  Apric0t
Output: 1

Input:  Ub40
Output: 0

Input:  POLICE
Output: 0
  4. Escreva uma função 
    int decimal(char str[]);

    que dada uma string que contém apenas dígitos (i.e., '0', '1', ... , '9') além do terminador '\0', a qual representa um inteiro não negativo em decimal (i.e., na base 10), retorna o valor desse inteiro.
    Exemplo:
    decimal("1234");
1234  // é um inteiro decimal

    • Determinar a maior palavra de uma string.
    • Modificar uma string, substituindo todas as ocorrências de um carácter ch1 por outro carácter dado ch2.
