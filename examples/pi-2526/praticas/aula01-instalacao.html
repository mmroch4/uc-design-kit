Brief Guide to C Installation

Using C

In this course, we will use the C programming language, so it is essential to have a version of GCCinstalled on your machine. GCC provides access to a preprocessor that interprets directives, a compiler that translates C code into machine code, and a linker that combines the generated machine code with the necessary libraries. In GNU/Linux systems, the preprocessor, compiler, and linker are executed sequentially using the gcccommand.

Compiling and Running

To compile and execute a C program (for example, a file named hello.c), you should invoke the compiler using the command line (shell):

$ gcc -o hello hello.c

This command produces an executable file named hello which you can run using the command:

$ ./hello
