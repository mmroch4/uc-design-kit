Exercício 1) Mooshak

  1. [PI038] Merge Sorted Arrays
      Alice and Bob each have a vector of grades sorted in ascending order. Your task is to merge them into a single sorted vector, without using any built-in sorting function.
    Read the problem statement carefully and try to submit an Accepted solution. Don't forget to test it first on your computer!

    Hint - Don't sort, merge

    - A naive approach would be to join the two arrays and sort the result. But there is a much more efficient way: since both arrays are already sorted, you can build the result by traversing them simultaneously, always choosing the smallest available element from the two. This is called merge.

    - You can use 3 pointers, one for each array (i for Alice's, j for Bob's) and a pointer k for the current position in the result array. At each step, compare the elements pointed to by the two pointers and copy the smaller one to the result, advancing the corresponding pointer.

    - Note: Don't forget the remaining elements or the special case (empty arrays)!

  2. [PI039] Shifting Numbers
      Joyce needs to rotate an array of integers k positions to the right (if k is positive) or to the left (if k is negative), in a circular way — elements that leave one end reappear at the other.
    Your task is to implement the function 
    void shift(int a[], int n, int k);

    The code for the main function and the printing function is already provided — you only need to write the shift function.
    Read the problem statement carefully and try to submit an Accepted solution.

    Hint

    - To solve the problem at hand, think about the following question: What does it mean to rotate k positions to the right?

    - Rotating to the right by 1 position means that each element at position i moves to position i+1, and the last element goes to position 0.

    - Generalized: the element that was at position i moves to position (i + k) % n.

    - Note: If you try to perform the rotation directly in array a, you will overwrite values before copying them. Think of a simple and fast way to solve this!


    Hint #2

    - The element that should go to position i after rotating k positions to the right originally came from position (i - k + n) % n. The + n ensures that the modulo result is not negative when k is positive and i - k < 0.

    - And for negative k? For negative k (left rotation), the formula (i - k + n) % n still works directly — subtracting a negative k is the same as adding its absolute value. You don’t need to handle this case separately.

  3. [PI040] Josephus Flower
      You have n petals numbered from 1 to n arranged in a circle. You go through the petals alternating between "keep" and "remove", returning to the beginning whenever necessary, until only one remains. Determine which petal is left.
    Read the problem statement carefully and try to submit an Accepted solution. Try to solve this problem without hints!

Exercise 2) Database of Teams, Players, and eSports Tournaments

Given a database containing information about players, teams, and eSports tournaments, the goal is to query it to obtain various pieces of information. The data structures that will be used by the program follow the specification below:

In the example, World eSports is tournament 0 and Elite Battle is tournament 2. The tournaments in which a player is registered to participate are identified by their index numbers in the Tournaments array. Similarly, the players who belong to a team are identified by their index numbers in the Players array. A player's id is a sequence of 7 characters (the first is the letter J followed by 6 digits).

  1. Write a function 
    void searchPlayer(char *nameWord);

    to print the code and name of the players whose name contains a word given by nameWord.
    For example, if the word is "Silva", it should print:
    Players whose name includes "Silva":
J012345 Andreia Silva
J067890 Marco Silva

    There should be no sorting of the data. Unless sorting is explicitly requested, the output should maintain the order in which the data appears in the data structures.
  2. Write a function 
    int id2Player(char *id, char *name);

    that writes into the character string name the name of the player corresponding to the identifier id (the function returns 0 if the player does not exist, and 1 otherwise).
  3. Write a function 
    int teamPlayers(char *teamName);

    that prints to standard output the list of player names belonging to a given team, with the team's name provided as a parameter to the function, and returns the total number of players in the team.
  4. Write a function 
    int playersInTournament(char *tournamentName, int *indices);

    that stores in the indices array the indexes (positions in Players) of the players who participated in a given tournament, specified by its name. The function returns the number of players matching this condition.
  5. Write a function 
    int averageTournamentsPerPlayer();

    that returns the average number of tournaments in which the players have participated.
  6. Write a function 
    int mostActivePlayers(int *indices);

    that stores in the indices array the indexes (positions in Players) of the players who participated in more tournaments than the average. The function returns the total number of such players.
  7. Write a function 
    int maxTournamentsPerYear(int year);

    that returns the maximum number of tournaments a player participated in during a given year.
  8. Write a function 
    int playerTournamentsYear(int playerPos, int year);

    that returns the number of tournaments in a given year that a player participated in.
    It is assumed that playerPos contains the index of the player's position in the Players array, and that it is a valid position.
  9. Write a function 
    int participatedInMultipleYears(int playerPos);

    that checks if a player participated in tournaments in multiple years. It returns a value different from 0 if true, and 0 otherwise.
    It is assumed that playerPos contains the index of the player's position in the Players array, and that it is a valid position.
