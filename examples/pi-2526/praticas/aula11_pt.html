Exercício 1) Pilhas e Filas com LinkedList

Nesta aula espera-se que utilize a mesma estrutura LinkedList do Exercício 1 da aula anterior (Aula Prática #10), recordando que uma pilha segue uma política LIFO (Last In, First Out) e uma fila segue uma política FIFO (First In, First Out).

Este exercício introduz também a utilização de header files (.h) para separar a interface de uma estrutura de dados da sua implementação. Considera a seguinte organização:

  • linkedlist.h : declara as estruturas e os protótipos das funções
  • main.c : inclui linkedlist.h e utiliza as funções

Exercício 3) Leitura e Escrita de Ficheiros

  1. Escreva um programa simples que lê um dado número de linhas da entrada padrão e escreve tais linhas num ficheiro de texto. Exemplo: 
    
Número de linhas: 4
Linha 1
Linha 2
Linha 3
Linha 4
  2. Escreva um programa que lê o ficheiro de texto criado no exercício anterior e guarda as linhas do ficheiro num vetor.
  3. Escreva uma função int numero_linhas(char *nome_ficheiro); que retorna o número de linhas dum ficheiro.
  4. Escreva um programa para contar palavras contidas num ficheiro. Considere que as palavras são sequências de “caracteres normais” (e.g., letras, algarismo ou sinais de pontuação) separados por “caracteres brancos” (espaços, tabulações ou mudança de linha, ou seja, ' ', '\t', ou '\n').
  5. Escreva um programa que lê o conteúdo de dois ficheiros de texto, "ficheiro1.txt" e "ficheiro2.txt", e escreve um novo ficheiro (com o nome "uniao.txt") obtido unindo os conteúdos dos dois ficheiros originais.
  6. Escreva uma função que permite a leitura de uma lista de contactos que está guardada em um ficheiro "contactos.txt" sem usar fscanf. Cada contacto é definido pelo nome da pessoa e pelo seu número de telemóvel e o ficheiro deve ter o seguinte formato: 
    
joaquina, 016002222
ana pinto, 0671445566
joao costa, 8442222
    Ou seja, cada nome é terminado por uma vírgula (',') e cada número de telemóvel por uma quebra de linha ('\n'). Os nomes e os números de telemóvel podem ser precedidos por espaços, como no exemplo acima.
    A função implementada deve apresentar no ecrã (saída padrão) os nomes e contactos lidos do ficheiro.
  7. Altere o programa anterior para incluir uma função de consulta por um contacto telefónico de forma eficiente.
    Para isso, crie um novo ficheiro "contactos_ordenados.txt" com todos os contactos telefónicos originais ordenados por ordem alfabética do nome da pessoas.
    Crie também uma função que permite a consulta pelo nome da pessoa utilizando a pesquisa binária (vantajosa em termos de eficiência).
    A função deve retornar o contacto de telemóvel caso exista, e -1 caso contrário.
  8. Para gerir a informação sobre os alunos inscritos a uma dada disciplina, é necessário guardar os seguintes dados:
    • Nome do aluno (string com no máximo 60 caracteres)
    • Número mecanográgico do aluno
    • Nota obtida na disciplina
    1. Defina os tipos Aluno e Turma. Para o efeito considere que a informação referente aos alunos de uma turma é armazenada numa lista ligada de alunos.
    2. Defina uma função int acrescentaAluno(Turma *t, Aluno a, FILE *f); que acrescenta a informação de um dado aluno a a uma turma t que está contida em um ficheiro f nomeado como "info_novos_alunos.txt". O ficheiro tem o seguinte formato: 
      Ana Filipa Silva, 202105440, 19
Pedro Tomás, 202005823, 10
José Filipe Fernandes, 202105635, 15
      A função implementada dever a retornar 0 se a operação for feita com sucesso e 1 caso contrário.
    3. Defina uma função Aluno *procura(Turma t, int numero); que procura o aluno com um dado número numero na turma t.
      A função deve retornar NULL se a informação desse aluno não existir; caso exista deve retornar o endereço onde essa informação se encontra.
    4. Defina uma função que determine quantos alunos obtiveram aproveitamento à disciplina (isto é, que obtiveram uma nota fina maior ou igual a 10). Escreva essa informação em um ficheiro "aprovados.txt".
