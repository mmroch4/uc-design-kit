  4. Mooshak [PI028] Permutations
      Dado um inteiro n, imprime todas as permutações dos números de 1 a n, cada uma numa linha, por ordem lexicográfica crescente.
    Leia o enunciado do problema com atenção e tente enviar uma solução Accepted.
    Sugestão

    - Uma permutação de n elementos é construída escolhendo um elemento para a primeira posição, e depois preenchendo as restantes n-1 posições com os elementos que sobram. Isso sugere uma abordagem recursiva.

    - Pode implementar uma função solve(x) que decide qual o elemento a colocar na posição x, e depois chame solve(x+1) para as posições seguintes.

    - O caso base é x == n: a permutação está completa, então pode imprimi-la.

    - Nota: A ordem lexicográfica é garantida automaticamente se, em cada posição, experimentar os elementos por ordem crescente (de 1 a n). Como itera sempre do menor para o maior, as permutações geradas ficam automaticamente ordenadas.

    - Aenção: Precisa de saber quais os elementos já colocados nas posições anteriores, para não os repetir.

    • Uma forma simples é manter um array visited[n], em que visited[i] = 1 significa que o elemento i já foi usado na permutação actual.
    • O passo de desmarcar (visited[i] = 0) é essencial, este chama-se backtracking e permite reutilizar o elemento noutras permutações.
