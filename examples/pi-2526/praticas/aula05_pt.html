Exercícios

  1. Sejam i uma variável inteira e p e q apontadores para inteiros. Indique quais das seguintes atribuições são corretas.

    Que atribuições são corretas? (pode haver mais do que uma)

    • p = i;
    • *p = i;
    • p = &q;
    • p = &i;
    • &i = p;
    • p = q;
    • p = *q;
    • *p = q;
    • *p = *q;

    Os dois lados têm de ter o mesmo tipo: p e q são int *, *p, *q e i são int. &q é int **, e &i não pode estar à esquerda de uma atribuição.
  2. Sejam i uma variável inteira e p um apontador para i. Indique quais das seguintes instruções de leitura e escrita são corretas.

    Que instruções são corretas? (pode haver mais do que uma)

    • printf("%d",i);
    • scanf("%d",i);
    • scanf("%d",&i);
    • printf("%d",p);
    • printf("%d",*p);
    • scanf("%d",p);
    • printf("%p",p);
    • printf("%p",i);
    • printf("%p",*p);

    %d escreve um int (i ou *p) e lê para um endereço de int (&i ou p); %p escreve um apontador (p). scanf("%d",i) passa um valor em vez de um endereço.
  3. Suponha que as seguintes declarações estão em execução:
    int a[] = {5, 15, 34, 54, 14, 2, 52, 72}; 
int *p = &a[1], *q = &a[5];

    Qual é o valor de *(p+3)?

    • 54
    • 14
    • 2

    p aponta para a[1], por isso p+3 aponta para a[4], que vale 14.

    Qual é o valor de *(q-3)?

    • 15
    • 34
    • 54

    q aponta para a[5], por isso q-3 aponta para a[2], que vale 34.

    Qual é o valor de q - p?

    • 4
    • 5
    • 16

    A diferença de dois apontadores para o mesmo array conta elementos, não bytes: 5 − 1 = 4.

    A condição p < q é verdadeira ou falsa?

    • Verdadeira
    • Falsa

    p aponta para a[1] e q para a[5], que está depois no array.

    A condição *p < *q é verdadeira ou falsa?

    • Verdadeira
    • Falsa

    Compara os valores: *p é 15 e *q é 2.
  4. Suponha que high, low e middle são todas variáveis apontadores do mesmo tipo, e que low e high apontam para elementos de um array. Corrija a declaração seguinte que, tal como está, não está correta.

      Leia o enunciado do problema e tente enviar uma solução Accepted. Não se esqueça de testar primeiro no seu computador!
    Sugestão #1 - Pensando no problema...

    - Quais as situações possíveis de output? Pense como as deves verificar...

    - Há as seguintes situações:

    1. alguém ganhou (o jogador X ou o jogador O)
    2. houve empate (se o tabuleiro está cheio)
    3. jogo incompleto (jogo ainda não terminou)

    - O que precisa de verificar para decidir o vencedor?

    • Um jogador ganha se preencher completamente uma linha, uma coluna, ou uma das duas diagonais.
    • Pense em como percorrer cada uma das opções e verificar se são compostas inteiramente por 'X' ou inteiramente por 'O'.

    - Se ninguém ganhou, precisa de saber se o tabuleiro está completamente preenchido.

    • Conta o número de casas ocupadas (com 'X' ou 'O') enquanto percorres o tabuleiro.
    • Se esse valor for igual a N×N, é empate; caso contrário, o jogo ainda não terminou.
    Sugestão #2 - Ler o tabuleiro de jogo...

    - O tabuleiro é uma matrix N×N de caracteres. Pode lê-lo linha a linha (i.e., como uma string) usando a função scanf("%s", ...).

    - Declara um array bidimensional de char com dimensão suficiente para guardar cada linha (nota: não se esqueça do carater '\0' no final de cada string).

      Leia o enunciado do problema e tente enviar uma solução Accepted. Não se esqueça de testar primeiro no seu computador!
    Sugestão #1 - Pensando no problema...

    - O jogo evolui em iterações.

    - Em cada iteração, o novo estado de todas as células é calculado com base no estado atual — nunca no novo estado que está a ser calculado.

    - Uma célula viva morre se tiver 0, 1 ou 4+ vizinhos vivos; uma célula morta nasce se tiver exatamente 3 vizinhos vivos.

    Sugestão #2

    - Comece por ler o estado inicial da matrix.

    - Inicie um ciclo que itere I vezes e em cada iteração calcule o próximo estado e substitua o atual.

    • Não altere a matrix enquanto ainda a está a ler para calcular os novos valores!
    • Se atualizar a célula (i, j) antes de processar os seus vizinhos, os cálculos dos vizinhos ficam errados.
    • Consegue encontrar um solução para resolver isto?

    - No final, imprima o estado final.

    - Comece por escrever apenas a leitura e a impressão, e confirma que estão corretas antes de tratar das iterações.

  5. Mooshak [PI014] Mundo da Tartaruga
      Leia o enunciado do problema e tente enviar uma solução Accepted. Não se esqueça de testar primeiro no seu computador!
    Sugestão

    - Gruarde o estado da tartaruga.

    • A tartaruga tem quatro atributos que precisas de guardar: posição (x, y), direção atual, e se a caneta está para cima ou para baixo.
    • Comece em (0,0), virada a Este, com a caneta levantada.

    - Há 4 direções: Norte, Oeste, Sul, Este.

    • Pode guardá-las como dois arrays de deslocamentos:
    • int dx[4] = { 0, -1, 0, 1 }; // Este, Norte, Oeste, Sul
    • int dy[4] = { 1, 0, -1, 0 };
    • A direção atual é um índice di nestes arrays. Virar à esquerda incrementa di, virar à direita decrementa.
    • Use o módulo 4 para "dar a volta".

    - Ao mover x passos, avance um passo de cada vez dentro de um ciclo. Em cada passo, atualize a posição e, se a caneta estiver para baixo, marque a célula com '*'. Mas, cuidado com os limites da grelha!

  6. Implemente uma função 
    void truncW(char text[], int n);

    em que a string text é composta por múltiplas palavras (as palavras estão separadas por um ou mais espaços) e um inteiro n, a função trunca todas as palavras de forma a terem no máximo n caracteres.
    Exemplo: 
    char text[] = "universidade, faculdade e fraternidade";
truncW(text, 4);  // text deverá ser "univ facu e frat"
    Nota: a palavra "e" tem apenas 1 caracter (1 < 4) e por isso permanece igual (isto é, não é truncada).

    Exemplo:

// result deverá ser 3, correspondente à substring "abc"
