  1. Write a program that reads the coefficients a, b and c of a quadratic equation a x 2 +bx+c=0 and determines the roots of the equation, indicating the type of roots, i.e., whether the equation has real roots or not, and if it does, whether it has a double root or two distinct roots. If it has roots, your program should return their value(s). Assume that the coefficients are integers. Your program should return the following messages, depending on the results obtained for the values read:
    "No roots!",
    "With a double root: x = value" or
    "With two distinct roots: x1 = value_1 and x2 = value_2".
    Replace value, value_1 or value_2 for the obtained values.
    Remember that to solve the problem of verifying the roots of a quadratic equation, we need to calculate the discriminant Δ= b 2 -4ac, and from the value of Δ, we can determine the type of roots:
    • If Δ<0, the equation has no real roots.
    • If Δ=0, the equation has a double real root.
    • If Δ>0, the equation has two distinct real roots.
