Exercício 1) Métodos para Listas Ligadas

Para os seguintes exercícios considere a seguinte estrutura de dados para representar listas ligadas de values inteiros baseada da estrutura apresentada nas aulas teóricas:

  1. Escreva uma função 
    int size(LinkedList *list);

    que calcula o comprimento de uma lista ligada.
  2. Escreva uma função 
    int removeEquals(LinkedList *list, int value);

    que remove todas as ocorrências de um dado valor inteiro value da lista list.
    A função deve retornar o número de elementos removidos da lista (ie., o número de ocorrências de value).
  3. Escreva uma uma função 
    void free(LinkedList *list);

    que liberta o espaço ocupado por uma lista.
  4. Escreva uma função 
    void concatList(LinkedList *listA, LinkedList *listB);

    que acrescenta à lista listA o conteúdo da lista listB.
  5. Escreva uma função 
    Node *invertList(LinkedList *list);

    que inverte a lista list (sem criar uma nova lista).
    A função deve retornar o novo primeiro elemento da lista.
  6. Escreva uma função 
    void insertOrd(LinkedList *list, int value);

    que insere (de forma ordenada) um novo elemento value na lista list. Considere que a lista list está ordenada.
  7. Escreva uma função 
    void printSort(Node *first);

    que recebe como argumento o primeiro elemento de uma lista ligada não ordenada e imprime no terminal os valores contidos na lista por ordem crescente de valor.
    Sugestão

    - pode usar um array de apontadores para guardar apontadores para os nós (elementos) da lista ligada e depois aplicar um algoritmo de ordenação (por exemplo: qsort()) ao array.

    - Mas tome atenção que neste caso os valores para comparar na ordenação são os campos de informação dos nós apontados pelos apontadores do array.

Exercício 2) Gestão de Livros

Tendo por base a estrutura de dados LinkedList e as funções desenvolvidas no Exercício 1 escreva um programa para gerir os registos de livros de uma biblioteca. Para cada livro a biblioteca tem registo da seguinte informação: identificador único (um valor inteiro), título (uma string), nome do autor (uma string), ano de publicação (um valor inteiro) e data de aquisição (uma estrutura com a informação relativa aos dia, mês e ano).

A tua tarefa é utilizar uma lista ligada para armazenar os dados relativos aos livros que existem na biblioteca, bem como para gerir o fluxo de livros que entram e saem da biblioteca.
Para isso deverá responder às seguintes questões de forma a adicionar novos métodos ou modificar os métodos desenvolvidos no Exercício 1 para adicionar novos livros, (possivelmente) remover outros livros, procurar por determinado indicador ou menos listar conjuntos de livros.

Nota: Faça as alterações necessárias às estruturas definidas no Exercício anterior de forma a cada nó (elemento) da lista ligada contenha a informação do livro correspondente. Pode usar a seguinte estrutura de dados para definir essa informação.


Como ponto de partida, pode ainda começar por usar o esqueleto de código apresentado mais abaixo e completar as partes em falta. Em alternativa, pode criar o seu próprio código de raiz.
  1. Desenvolva uma função que adiciona novo livro new_book à lista de livros list. A função deve adicionar o livro ao final da lista. As informações do livro deve ser fornecidas na entrada padrão com os seguintes campos em cada linha: ID, Título, Autor, Ano de Publicação, e Data de Aquisição. 
    void add_new_book(LinkedList *list, Book new_book);
  2. Desenvolva uma função que imprime na saída padrão os dados de um dado livro, dado o seu ID (id). Se o livro não existir, a função deve imprimir uma mensagem apropriada. 
    void print_by_id(LinkedList *list, int id);
  3. Desenvolva uma função que imprime todos os livros de um dado autor cujo nome contenha o nome fornecido pelo utilizador (name). 
    void print_by_author(LinkedList *list, char *name);

    Sugestão

    - utilize a função strstr() na biblioteca string.h para procurar uma substring dentro de uma string maior.

  4. Desenvolva uma função que imprime todos os livros da biblioteca ordenados por título (ordem alfabética). 
    void printSortByTitle(Node *first);

    Sugestão

    - use um array de apontadores e a função qsort() com a função strcmp().

  5. Desenvolva uma função para apagar todos os livro cuja data de aquisição é anterior ao ano dado como input da função. A função deve retornar o número de livros apagados ou uma mensagem apropriada se não existe nenhum livro nessas condições. 
    int remove_by_year(LinkedList *list, int year);
