Node Balance

In this problem, you should only submit a file named pi072.c containing a line with #include "binarySearchTree.h" and the implementation of the functions findNode, nodeBalance and treBalance as described below (a complete program is not required). Check code at the end and explanation on how to compile.

You may assume that on Mooshak you will have access to the binary search tree implementation code (binarySearchTree.h and binarySearchTree.c) as provided in class.

Functions to Submit

  • BTNode *findNode(BTNode *n, NodeInfo val)

    Searches the BST rooted at n for a node with value val. Returns a pointer to that node, or NULL if not found. Take advantage of the BST property for an efficient O(h) search.

  • int nodeBalance(BTNode *n, NodeInfo val)

    Returns the balance of the node containing val in the subtree rooted at n. The balance is defined as:
    balance = height(right subtree) - height(left subtree)
    Returns 0 if val is not found.

  • int treBalance(BTree *t, NodeInfo val)

    Wrapper that calls nodeBalance on the root of tree t.

The figure below shows the BST built by inserting 42 25 56 21 45 64 15 61 in order. For this tree:

  • balance(t, 42) = 0 — left and right subtrees have the same height
  • balance(t, 25) = -2 — left subtree is 2 taller than right
  • balance(t, 56) = 1 — right subtree is 1 taller than left
  • balance(t, 88) = 0 — value not in tree

Input/Output Examples

Call Result
treBalance(t, 42)   [tree: 42 25 56 21 45 64 15 61] 0
treBalance(t, 25) -2
treBalance(t, 56) 1
treBalance(t, 88)   [not in tree] 0

How to compile locally

To compile locally you will need the following files:

  • binarySearchTree.h — binary search tree declarations. The type NodeInfo is set to int.
  • binarySearchTree.c — BST implementation (insert, BST-optimised search, height, traversals, etc.).
  • pi072.c — your code with the required functions.
  • test072.c — file with the main() function handling input reading and output printing.

To compile, run in the folder where the files are located: gcc test072.c binarySearchTree.c pi072.c, which will generate an executable a.out.

Test code, file: test072.c

// PI072 Testing

#include <stdio.h>
#include "binarySearchTree.h"

int main(void) {
  BTree t;
  initTree(&t);

  /* Read n values and insert them into the BST */
  int n;
  scanf("%d", &n);
  for (int i = 0; i < n; i++) {
    int x;
    scanf("%d", &x);
    insertBST(&t, x);
  }

  /* Read q queries and print the balance of each */
  int q;
  scanf("%d", &q);
  for (int i = 0; i < q; i++) {
    int x;
    scanf("%d", &x);
    printf("balance(t, %d) = %d\n", x, treBalance(&t, x));
  }

  freeTree(t.root);
  return 0;
}

Funções a submeter

  • BTNode *findNode(BTNode *n, NodeInfo val)

    Pesquisa na BST com raiz em n um nó com valor val. Devolve um ponteiro para esse nó, ou NULL se não existir. Aproveite a propriedade da BST para uma pesquisa eficiente O(h).

  • int nodeBalance(BTNode *n, NodeInfo val)

    Devolve o balanço do nó que contém val na subárvore com raiz em n. O balanço é definido como:
    balanço = altura(subárvore direita) - altura(subárvore esquerda)
    Devolve 0 se val não existir na árvore.

  • int treBalance(BTree *t, NodeInfo val)

    Função wrapper que chama nodeBalance na raiz da árvore t.

A figura abaixo mostra a BST construída inserindo 42 25 56 21 45 64 15 61 por ordem. Para esta árvore:

  • balance(t, 42) = 0 — as subárvores esquerda e direita têm a mesma altura
  • balance(t, 25) = -2 — a subárvore esquerda é 2 níveis mais alta que a direita
  • balance(t, 56) = 1 — a subárvore direita é 1 nível mais alta que a esquerda
  • balance(t, 88) = 0 — valor não existe na árvore

Chamada Resultado

Como compilar localmente

Para compilar localmente vai precisar de ter os seguintes ficheiros:

  • binarySearchTree.h — declarações da árvore binária de pesquisa. O tipo NodeInfo está configurado para int.
  • binarySearchTree.c — implementação da BST (inserção, pesquisa optimizada, altura, travessias, etc.).
  • pi072.c — o seu código com as funções pedidas.
  • test072.c — ficheiro com a função main() que trata da leitura e escrita.

Para compilar execute na pasta onde estão os ficheiros: gcc test072.c binaryTree.c pi072.c, que vai gerar um executável a.out.

Código para testes, ficheiro: test072.c

// PI072 Testes

#include <stdio.h>
#include "binaryTree.h"

int main(void) {
  BTree t;
  initTree(&t);

  /* Ler n valores e inserir na BST */
  int n;
  scanf("%d", &n);
  for (int i = 0; i < n; i++) {
    int x;
    scanf("%d", &x);
    insertBST(&t, x);
  }

  /* Ler q queries e imprimir o balanço de cada */
  int q;
  scanf("%d", &q);
  for (int i = 0; i < q; i++) {
    int x;
    scanf("%d", &x);
    printf("balance(t, %d) = %d\n", x, treBalance(&t, x));
  }

  freeTree(t.root);
  return 0;
}
