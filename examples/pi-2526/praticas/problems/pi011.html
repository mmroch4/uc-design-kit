[PI011] Tic-Tac-Toe

Who doesn't know the famous tic-tac-toe game? In this problem you are asked, given a tic-tac-toe board, with some moves possibly already played, to analyze it and determine whether any of the players has won. To make things a little more interesting, imagine a generalization of the game, still on a square board, but which can have a dimension different from 3x3. As in the original game, players take turns and win if they manage to completely fill a row, a column, or a diagonal.

Task

You are given a tic-tac-toe board pre-filled with some moves possibly already played. Your task is to determine the state of the game.

Input

The first line contains a number N (1 <= N <= 101), indicating the dimension of the board (which is always square).
This is followed by N lines, each with N characters (X, O or .) representing the current state of the game.
As expected, X and O represent a cell occupied by one of the two players, and . represents an empty cell.
You may assume that the board will always represent a valid game state (for example, there will never be two winners).

Output

The output should be a single line indicating the state of the game:
  • Ganhou o X - If player X has completely filled a row, column, or diagonal
  • Ganhou o O - If player O has completely filled a row, column, or diagonal
  • Empate - If neither player has won and the game has finished
  • Jogo incompleto - If neither player has won and the game has not finished yet
