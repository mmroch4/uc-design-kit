Problemas do MooshakMooshak problems

Os problemas para submeter no Mooshak, por aula prática. Cada aula vale 10 % da resolução de exercícios; para chegar aos 100 % basta resolver os exercícios principais. Um problema só conta se passar todos os testes (accepted) dentro do prazo. Ver também a ajuda do Mooshak.

The problems to submit on Mooshak, by lab class. Each class is worth 10 % of the weekly problems grade; solving the main exercises is enough for 100 %. A problem only counts if it passes all tests (accepted) before the deadline. See also the Mooshak help.
