The World of the Turtle

The Logo programming language, created in 1967, was primarily designed to aid in learning geometric concepts, spatial exploration, and basic programming principles. One of the features provided by this language is the turtle (derived from a robot with that name), which represents a cursor on the screen to which movement and drawing instructions can be given.

The turtle has a built-in pen which, when down, leaves a trail (drawn on the screen). Whenever the pen is up, its movement does not leave a trail (and nothing is drawn on the screen).

Your first task is to start by defining a world for the turtle; create a turtle in this world and move it according to a set of instructions to create an image.

Assume that the turtle's world is defined by a grid with a given height and width, through which the turtle can move according to the following set of instructions:

  • U (up): lifts the pen, leaving no trail;
  • D (down): lowers the pen, leaving a trail;
  • F x (forward): moves forward x steps;
  • L (left): turns left;
  • R (right): turns right.

The turtle is associated with a grid, a position (x, y), a direction (North, South, East, and West), and the pen position (up or down).

When created, the turtle is positioned at (0,0), taking the top-left corner of the grid as a reference, is facing East, and has the pen up.

If instructions are given that would move the turtle outside the grid boundaries, it moves as far as it can to the edge and stays there.

Once the set of instructions given to the turtle has been executed and an image created, the second and third parts of your task consist of analyzing the image and recognizing a pattern within it.

Input

The first line of input contains a flag value that can be 0, 1, or 2.
The next line contains two integers LINS and COLS (1 <= LINS, COLS <= 10), indicating the number of rows and columns that define the image grid, respectively.
The following lines contain the instructions to be given to the turtle, one instruction per line. The set of instructions ends with the word end.
Each instruction of the form F x must satisfy 1 <= x <= 20.
From this point in the input, the pattern to search for in the image is defined. The first line contains two integers N and M (1 <= N, M <= 10), indicating the number of rows and columns of the pattern, respectively. The following N lines define the pattern. Each of these lines contains M characters ('.' or '*'), left-aligned and separated by a single character space.

Output

If the flag value is 0, you should display on the screen the result of executing the instructions given to the turtle. To do this, assume that all positions on the grid are initially filled with '.' and that the turtle, when the pen is down, marks the positions it passes over with '*'. The grid positions should be displayed left-aligned with a spacing of 1 character.

If the flag value is 1, you should indicate, separated by a space, the percentage of grid positions marked by the turtle and the number of rows and columns that have no marks.

If the flag value is 2, you should read from the input the pattern to search for and respond with Yes if it is found in the image created by the turtle, and No otherwise.
