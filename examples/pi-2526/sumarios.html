SumáriosLecture summaries

O que foi dado em cada aula teórica. Cada sumário liga à sua semana, onde estão os slides e o guião da prática.

What was covered in each lecture. Each summary links to its week, with the slides and the lab guide.

  1. 19 fev

    Apresentação Considerações gerais sobre o programa, bibliografia, funcionamento das aulas e método de avaliação. Breve introdução dos capítulos da UC. Introdução ao C. Breve história da linguagem C. Um programa simples em C. A função main(). Fases de compilação. Diretivas de compilação. Comentários. A função printf(). Variáveis. Exemplos.

  2. 19 Feb

    General considerations about the syllabus, bibliography, class structure, and assessment method. Brief introduction to the course chapters. Introduction to C – A brief history of the C language. A simple program in C. The main() function. Compilation phases. Compilation directives. Comments. The printf() function. Variables. Examples.

  3. 24 fev

    Introdução ao C (cont.) A função scanf(). Exemplos. Atribuições. Operadores binários e unários. Precedência de operadores. Associatividade. Operadores de incremento e decremento. Tipos básicos de dados. Dimensão dos inteiros (unsigned, short e long). Constantes. Leitura e escrita de inteiros. Números em vírgula flutuante. Leitura e escrita. Conversão de tipos (type casting).

  4. 24 Feb

    Introduction to C (cont.) – The scanf() function. Examples. Assignments. Binary and unary operators. Operator precedence. Associativity. Increment and decrement operators. Basic data types. Integer size (unsigned, short, and long). Constants. Reading and writing integers. Floating point numbers. Reading and writing. Type conversion (type casting).

  5. 26 fev

    Introdução ao C (cont.): Operadores relacionais, lógicos, de bit. Instruções condicionais: if-else, switch-case e exemplos. Instruções de ciclo: while, do-while, e for. Desenho de tabuleiro de xadrez, instruções break e continue.

  6. 26 Feb

    Introduction to C (cont.) – Relational, logical, and bitwise operators. Conditional statements: if-else, switch-case, and examples. Loop statements: while, do-while, and for. Chessboard drawing, break and continue statements.

  7. 3 mar

    Introdução ao C (cont.): Dados do tipo char. Escrita e leitura de carateres, output da tabelas ASCII, leitura e escrita com getchar() e putchar(). Funções. A função isPrime(). Chamada de funções e passagem de argumentos. A instrução return. A função main(). Vetores (arrays): declaração, indexação, inicialização. Exemplos. Tipos primitivos de dados: integers, floats, doubles and characters. Qualificadores unsigned, short e long. Escrita de números em binário. Verificar se um número tem dígitos repetidos.

  8. 3 Mar

    Introduction to C (cont.) – Char data type, character reading and writing, ASCII table output, reading and writing with getchar() and putchar(). Functions. The isPrime() function. Function calls and argument passing. The return statement. The main() function. Arrays (vectors): declaration, indexing, initialization. Examples. Primitive data types: integers, floats, doubles, and characters. Unsigned, short, and long qualifiers. Writing numbers in binary. Checking if a number has repeated digits.

  9. 5 mar

    Arrays multidimensionais. Exemplo com baralho de cartas. Exemplo com geração de aleatórios. Adição de matrizes. Strings e funções com arrays como argumentos. String como vetor de carateres. leitura de strings (scanf() and gets()), escrita (printf() and puts()). Arrays como argumentos de funções. Função para remover duplicados de um array.

  10. 5 Mar

    Multidimensional arrays. Example with a deck of cards. Example with random number generation. Matrix addition. Strings and functions with arrays as arguments – Strings as character arrays. Reading strings (scanf() vs gets()), writing (printf() and puts()). Arrays as function arguments – Function to remove duplicates from an array.

  11. 10 mar

    Função para verificar se um elemento ocorre num vetor, comprimento de uma string, inversão de uma string, cópia de uma string origem para destino, concatenação de strings, procura e comparação. Apontadores: organização da memória, noção de apontadores em C, declaração de um apontador, endereço de uma variável (operador &), valor apontador por uma variável apontador (operador *), atribuição, apontadores como argumentos de funções, apontadores e arrays, funções que retornam apontadores. Revisão de algumas funções de manipulação de strings representadas por vetores de carateres mas agora trabalhadas com apontadores para carateres.

  12. 10 Mar

    Function to check if an element occurs in an array, string length, string reversal, copying a string from source to destination, string concatenation, searching, and comparison. Pointers – Memory organization, concept of pointers in C, pointer declaration, address of a variable (operator &), dereferencing a pointer variable (operator *), assignment, pointers as function arguments, pointers and arrays, functions that return pointers. String manipulation using pointers – Revisiting some string manipulation functions previously represented as character arrays, now implemented using character pointers.

  13. 12 mar

    Apontadores: Acesso a matrizes multidimensionais. Exercícios sobre matrizes: 1) determinar algumas estatísticas relacionadas com os registo dos resultados obtidos por alunos em diferentes cursos (matriz com notas); 2) resposta a questões relacionadas com o registo anual de precipitação num conjunto de estações (matriz com valores de precipitação).

  14. 12 Mar

    Pointers – Accessing multidimensional arrays. Exercises on matrices - 1) determining some statistics related to the records of results obtained by students in different courses (matrix with grades); 2) solving questions related to annual precipitation records in a set of weather stations (matrix containing precipitation values).

  15. 17 mar

    Exercícios sobre matrizes (continuação). Recursividade: introdução à recursão, recursão linear e binária, inversão recursiva dos elementos de um vector.

  16. 17 Mar

    Exercises on matrices (continuation). Recursion – Introduction to recursion, linear and binary recursion, recursive reversal of array elements.

  17. 19 mar

    Recursividade: torres de hanoi, geração de permutações como exemplo de recursão com retrocesso (backtracking).

  18. 19 Mar

    Recursion – Tower of Hanoi, generating permutations as an example of recursion with backtracking.

  19. 24 mar

    Pesquisa e ordenação. Pesquisa sequencial e binária. Ordenação pelo método de seleção de mínimo ou máximo, pelo método de inserção, método da bolha.

  20. 24 Mar

    Search and sorting. Sequential and binary search. Sorting using the minimum or maximum selection method, insertion method, bubble sort method.

  21. 26 mar

    Estruturas de Dados em C. Definição e uso de struct. vetores de estruturas. Apontadores para estruturas. Unions e enumerations.

  22. 26 Mar

    Data Structures in C. Definition and use of struct. Arrays of structures. Pointers to structures. Unions and enumerations.

  23. 14 abr

    Gestão dinâmica de memória. Funções de malloc(), sizeof(), calloc(), free(). Apontadores de apontadores.

  24. 14 Apr

    Dynamic memory management. Functions malloc(), sizeof(), calloc(), free(). Pointers to pointers.

  25. 16 abr

    Gestão dinâmica de memória (cont.). apontadores para funções. Resolução de exercícios: leitura e processamento de frases. Leitura de palavras.

  26. 16 Apr

    Dynamic memory management (cont.) pointers to functions. Exercises: reading and processing of sentences. Reading words.

  27. 21 abr

    Resolução de exercícios de preparação para a avaliação prática.

  28. 21 Apr

    Practice exercises for practical evaluation.

  29. 23 abr

    Debugging de programas. GDB e lldb. Uso de asserções como forma de programação defensiva para verificação de condições em programas.

  30. 23 Apr

    Program debugging. GDB and lldb. Use of assertions as a form of defensive programming to verify conditions in programs.

  31. 28 abr

    Recursividade e Ordenação. Algoritmo de "flood-fill" aplicado a problemas com representação em matrizes. Métodos de ordenação: merge-sort.

  32. 28 Apr

    Recursion and Sorting. "Flood-fill" algorithm applied to problems with matrix representation. Sorting methods: merge sort.

  33. 30 abr

    Ordenação (cont.): método quick-sort; ordenação com a função qsort(). Listas. Definição de pilhas e filas com memória estática. Implementação de pilhas com vetores. Funções de manipulação de pilhas: initStack(), isEmpty(), size(), push(), pop(), top().

  34. 30 Apr

    Recursion and Sorting:. Quick-sort method. Sorting with qsort(). Lists. Definition of stacks and queues with static memory. Implementation of stacks using arrays. Stack manipulation functions: initStack(), isEmpty(), size(), push(), pop(), top().

  35. 12 mai

    Listas (cont.) Implementação de filas com vetores circulares. Funções de manipulação de pilhas: initQueue(), isEmpty(), size(), removeFirst(), addLast(), first(). Definição de listas ligadas com alocação dinâmica de memória. Implementação em C, nomeadamente funções initList(), isEmpty(), size(), addFirst(), addlast(), removeFirst(), removeLast(), addAt(), removeAt(), indexOf().

  36. 12 May

    Lists (cont.). Implementation of queues using circular arrays. Queue manipulation functions: initQueue(), isEmpty(), size(), removeFirst(), addLast(), first(). Definition of linked lists with dynamic memory allocation. Implementation in C, including functions initList(), isEmpty(), size(), addFirst(), addLast(), removeFirst(), removeLast(), addAt(), removeAt(), indexOf().

  37. 14 mai

    Listas (cont.) Implementação de pilhas e filas com memória dinâmica. Resolução de exercícios sobre listas. Problema de gestão de aeroportos (Filas).

  38. 14 May

    Lists (cont.) Implementation of stacks and queues with dynamic memory. Solving exercises on lists. Airport management problem (Queues).

  39. 19 mai

    Breve introdução à complexidade e eficiência de algoritmos. Noção de eficiência, complexidade linear, quadrática exponencial e logarítmica.

  40. 19 May

    Brief introduction to algorithm complexity and efficiency. Concept of efficiency, linear, quadratic, exponential, and logarithmic complexity.

  41. 21 mai

    Leitura e escrita em ficheiros. Abertura e fecho de ficheiros. Escrita e leitura de ficheiros de texto. Escrita e leitura de ficheiros binários. Passagem via argumentos da função main.

  42. 21 May

    Reading and writing to files. File opening and closing. Writing and reading text files. Writing and reading binary files. Passing via main function arguments.

  43. 26 mai

    Módulos e Makefiles. Resolução de exercícios de preparação para a avaliação prática.

  44. 26 May

    Modules and Makefiles. Solving the exercises from the practical evaluation.

  45. 28 mai

    Breve introdução às árvores binárias e árvores binárias de pesquisa. Conceitos e definição de estruturas de dados em C. Algumas funções: contar o número de nós da árvore, verificar se a árvore contém um determinado valor, pesquisa em profundidade, inserção de valores em árvores BST.

  46. 28 May

    Brief introduction to binary trees and binary search trees. Concepts and definition of data structures in C. Some functions: count the number of nodes in the tree, check if the tree contains a given value, depth-first search, insertion of values in BSTs.

  47. 2 jun

    Resolução de exercícios sobre árvores binárias.

  48. 2 Jun

    Solving the exercises about binary trees.
