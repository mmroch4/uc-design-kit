Exercício 2) Vários exercícios simples sobre listas

Resolve os seguintes exercícios e submete-os também no Mooshak para testar as tuas resoluções. Para testar no teu computador, chama os métodos no main depois de criares listas com os exemplos que quiseres verificar.

Resolve e submete o problema [ED188] Devolver elemento numa dada posição.

Dicas
  • Tens de percorrer pos posições e depois devolver o atributo value do nó nessa posição.
  • Cuidado com os casos em que a posição é inválida (menor que zero ou maior ou igual ao tamanho).

Resolve e submete o problema [ED189] Remover elemento numa dada posição.

Dicas
  • Tens de conseguir parar antes de chegar ao elemento que queres remover, para atualizar o next do anterior.
  • Cuidado com os casos excecionais: qual é o nó anterior ao primeiro?
  • Não te esqueças de atualizar o size.

Resolve e submete o problema [ED190] Cópia de uma lista.

Dicas
  • Começa por criar uma nova lista do tipo… SinglyLinkedList<T>!
  • Depois só tens de ir percorrendo a lista e chamando addLast na nova lista.
  • No fim, devolve essa nova lista.

Resolve e submete o problema [ED191] Duplicando elementos.

Dicas

Para cada elemento da lista tens de criar um novo Node e modificar os atributos next em conformidade.

Resolve e submete o problema [ED192] Contando elementos.

Dicas

Não te esqueças de usar o método equals para comparar (por exemplo, var1.equals(var2) compara o conteúdo de var1 com var2 e devolve true se forem iguais, ou false caso contrário). Um == apenas compara se as referências "apontam" para o mesmo endereço de memória.

Exercícios extra para consolidação de conhecimentos

Podes resolver o problema [ED193] Remover todas as ocorrências de um elemento e submetê-lo no Mooshak.

Dicas

Cuidado com a remoção de vários números seguidos…

Experimenta usar o método count numa lista de pares como a que definiste atrás (objetos do tipo Pair). O que acontece? Os objetos têm um equals padrão que é equivalente ao ==. Para ter o comportamento desejado (comparar os dois números do par) é preciso implementar esse método. Faz override do método padrão e implementa um equals correto para a tua classe Pair. Testa a tua implementação fazendo contagens e verificando se o resultado está certo.

Implementa mais alguns métodos de listas com operações que julgues úteis, treinando também a escolha da assinatura de cada método. Algumas sugestões:

  • devolver a posição da primeira (ou última) ocorrência de um dado elemento na lista;
  • retirar todos os elementos que estão numa posição ímpar (ou par);
  • concatenar (juntar) duas listas.

Para melhorar a eficiência dos métodos que precisam de aceder ao fim da lista (getLast e addLast), acrescenta um atributo private Node<T> last à tua classe de lista ligada. Faz as modificações necessárias em todos os métodos implementados (no fim têm de ficar corretos não só os valores de first e size, mas também o de last). Este é um tradeoff típico: melhorar a eficiência tornando (ligeiramente) mais complexa a implementação.
