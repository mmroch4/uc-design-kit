Exercícios

Introdução e conceitos associados. Nas teóricas falámos de vários conceitos que deves rever, em particular:

  • Interface: definição dos métodos de um TAD (em abstrato, sem indicar implementação).
  • Implementação de uma interface: uma classe X que implementa uma interface Y é declarada como class X implements Y e tem de implementar todos os métodos definidos na interface.
  • TAD Conjunto: um tipo abstrato de dados que implementa um conjunto (usámos como exemplo um conjunto de números inteiros e operações como adicionar, remover ou verificar se um número está contido no conjunto).

Resolve o problema [ED247] TAD Conjunto (ArrayListIntSet). Podes também submeter a tua solução no Mooshak. Vais ter de implementar dois métodos novos: equals e intersection.

Dicas
  • Deves submeter um ficheiro apenas com a classe que implementa a interface, ArrayListIntSet.
  • Em ambos os métodos recebes um IntSet s, por isso só podes chamar os métodos da interface sobre esse objeto s.
  • Para fazer o equals(IntSet s) podes, por exemplo, verificar se o tamanho de ambos os objetos (this e s) é igual e depois percorrer todos os elementos de this e verificar se estão em s (usando o método contains).
  • Para fazer o intersection(IntSet s) começa por criar um novo conjunto tmp (como criar? Vê o código exemplo no enunciado… e deve ter espaço para quantos elementos?); depois percorre todos os elementos de this e verifica se estão em s (usando o método contains); caso estejam, adiciona-os a tmp.

Descobrir a quantidade de números únicos. Usa a implementação de conjunto para descobrir a quantidade de números únicos (não repetidos) no input. O algoritmo deve ser algo como:

  • criar um conjunto s vazio;
  • enquanto houver um número x para ler, adicionar x ao conjunto s;
  • no fim, escrever a quantidade de elementos em s.

A ideia é usar um array de valores booleanos para dizer se um número está ou não no conjunto:

  • manter um array isElem[] de valores booleanos (verdadeiro ou falso);
  • isElem[i] diz se o número i está ou não no conjunto;

Exercício de submissão extra para consolidação de conhecimentos

Os tipos de dados primitivos do Java têm limites para os números que conseguem representar. O objetivo deste exercício é implementar um TAD que represente números inteiros positivos arbitrariamente grandes, ou seja, com o número de dígitos que quisermos (o Java já tem uma classe para representar números com precisão arbitrária, mas aqui a ideia é seres tu a implementar uma).

Resolve o problema [ED185] TAD Números Arbitrariamente Grandes (BigNumber) e submete-o no Mooshak.

Dica: armazenar o número

Uma sugestão simples é usar um array com um dígito em cada posição, o que te vai simplificar a vida depois para somar e multiplicar. Coloca o dígito menos significativo na posição zero, e assim por diante. Por exemplo, o número "23454760" ficaria guardado num array assim:

Dígitos de 23454760, do menos para o mais significativo
06745432

Se optares pelo array de dígitos, podes simplesmente declará-lo com o tamanho máximo permitido (1000 dígitos) e guardar o número de dígitos significativos atualmente armazenados numa outra variável size, por exemplo.

Para converter um carácter no dígito correspondente, basta subtrair-lhe '0' (por exemplo, char c = '2'; int d = c - '0'; coloca um 2 no inteiro d).
