Class #07 · Dynamic Programming II

Partitions, games, DAGs, counting, search.

Main learning outcomes for this class

  • I know the minimax principle for games and how to use DP for solving simple game problems.
  • I know the linear partitions problem and how to use DP to obtain optimal partitions.
  • I know the concept of DAGs and how to use DP to solve problems in DAGs.
  • I know the concept of bitmasks and how to use them in DP states; I know the TSP problem and how to solve it in O(n² 2ⁿ) using DP and bitmasks.
  • I know the concept of counting with DP

DP on a DAG computes the states in a topological order, so every state comes after the states it depends on. Kahn's algorithm finds such an order (and a cycle, when there is no DAG); switch to the DFS version and compare.
