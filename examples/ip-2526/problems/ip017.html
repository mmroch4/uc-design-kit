[IP017] Sum me up!

To understand the context of this problem, read the class #02 exercise sheet. After the deadline the problem stays open on Mooshak, but submissions no longer count towards your grade.

Have you ever looked at a number and thought, "What if I could just add up all its digits and see what I get?"

The Problem

Write a program that takes a positive integer num as input and calculates the sum of its digits. For example, if the input number is 123, the output should be 1 + 2 + 3 = 6.

Input

The input consists of a single integer num.

Output

The output should be a single integer representing the sum of the digits of the input number.

Constraints

The following limits are guaranteed in all the test cases that will be given to your program:

1 ≤ num ≤ 109 The input number must be a positive integer

Example Input 1

781

Example Output 1

16

Example Input 2

16250301

Example Output 2

18
