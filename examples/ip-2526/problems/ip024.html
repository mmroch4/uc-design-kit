[IP024] Freezing in here

To understand the context of this problem, read the class #03 exercise sheet. After the deadline the problem stays open on Mooshak, but submissions no longer count towards your grade.

In this problem you should submit a function as described. Inside the function do not print anything that was not asked!

The name of the .py source file you submit to Mooshak should NOT start with a digit (you will get an error if you submit it like that).

Brrr... It’s getting cold, isn't it? With the temperature dropping outside, you find yourself wondering: "Just how chilly is it in Fahrenheit?"

The Problem

Write a function named celsius_to_fahrenheit(celsius) that given a float indicating a temperature, returns its conversion from Celsius to Fahrenheit using the following formula: \[ F = \left( C \times \frac{9}{5} \right) + 32 \] where C is the temperature in Celsius and F is the temperature in Fahrenheit.

Constraints

The following limits are guaranteed in all the test cases that will be given to your program:

-273.15 ≤ celsius ≤ 1000 The temperature in Celsius

Example Function Calls

print( round(celsius_to_fahrenheit(-273.15), 2) )
print( round(celsius_to_fahrenheit(100),     2) )
print( round(celsius_to_fahrenheit(0),       2) )

Example Output

-459.67
212.0
32.0
