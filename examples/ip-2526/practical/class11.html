Skills

With the exercises in this class you will develop the following skills:

  • Understand exceptions and learn to identify, catch, raise and handle different types of runtime errors
  • Antecipate and prevent exceptions, writing defensive code that avoids crashes before they happen
  • Debug more complex workflows, involving unpredictable inputs

If you feel stuck, go back and revise lectures.

This week's theme for the exercises is The Matrix.
