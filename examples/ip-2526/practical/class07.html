Skills

With the exercises in this class you will develop the following skills:

  • Explore function definition and function calling
  • Understand the concept of dictionaries and how you can use them in Python
  • Know how to traverse, insert, remove and modify elements in dictionaries
  • Understand the concept of sets and how you can use them in Python
  • Know how to traverse, insert and remove elements in sets
  • Gain experience with some algorithmic patterns

If you feel stuck, go back and revise lecture T10: Sets and T14: Dictionaries.
