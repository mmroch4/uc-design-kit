Skills

With the exercises in this class you will develop the following skills:

  • Explore function definition and function calling
  • Understand the concept of lists and how you can use them in Python
  • Know how to insert, remove and modify elements in lists
  • Know how to call auxiliary list methods, such as count and sort
  • Understand that a list variable is essentially a reference to the list
  • Understand how matrices can be represented as a list of lists
  • Gain experience with some algorithmic patterns

If you feel stuck, go back and revise all the lectures, but in particular T07: Tuples and Lists, T08: More (on) Lists and T09: Advanced Lists.
