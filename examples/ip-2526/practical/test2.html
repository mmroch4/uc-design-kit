Information for the 2nd practical test

General information

If you have a well-founded reason to go to only one of the shifts, send an email to Bernardo Portela and Pedro Ribeiro until 13:00 of 15 December explaining your situation, and it will be considered.

Method
Individual. Practical problems for which you submit Python code to Mooshak and receive feedback that might include public test cases, like in the practical classes.
Language
All problem statements are available in English and in Portuguese.
Environment
Linux, with Python available at the command line and the usual editors and IDEs. You have access to documentation (a local copy of the Python docs) and to a local copy of the lecture notebooks (a static HTML version).
Scoring
Worth 4 points out of 20 (20% of your grade). See the calculation formula of the final grade.
  • 20% Dictionaries and sets Goals and training problems
  • 20% Exceptions Goals and training problems
  • 20% Advanced strings Goals and training problems
  • 20% Efficiency Goals and training problems
  • 10% Recursion Goals and training problems
  • 10% Structured Programming Goals and training problems

In each exercise there might be partial scoring (e.g. passes some tests, fails on others).

When submitting, you will know the score you got on all tests. Your grade on a problem is the grade of your best submission on that problem (the one with the highest score), and you can submit as many times as you want (with 60 seconds between submissions).

Specific goals for each exercise and training problems

Exercise 1 · Dictionaries and sets

Something at the level of the dictionary main exercises of practical class #07 (dictionaries and sets), where you will implement a function and will need to used dictionaries and/or sets.

Training problems: IP067 IP068 IP069 IP070 IP071 IP072 IP073 IP074

And also: IP075 IP076 IP077

Exercise 2 · Exceptions

Something at the level of the main exercises of practical class #11 (exceptions), where you will implement a function and will need to handle exceptions.

Training problems: IP102 IP103 IP104 IP105

And also: IP106

Exercise 3 · Advanced strings

Something at the level of the main exercises of practical class #08 (advanced strings), writing a function that receives input from the arguments and will need to handle strings.

Training problems: IP079 IP080 IP081 IP082 IP083

And also: IP084 IP085 IP086 IP087

Exercise 4 · Efficiency

Something at the level of the set main exercises of practical class #06 (correction and efficiency), where you will implement a function. To obtain full score your code will need to be efficient and you should be aware of the algorithmic techniques discussed in practical class #06 (namely sliding windows and prefix sums).

Training problems: IP059 IP060 IP061 IP062

And also: IP063 IP064

Exercise 5 · Recursion

Something at the level of the main exercises of practical class #09 (recursion), writing a function that receives input from the arguments. The problem will be suited to a recursive solution (but if you can make it withouth recursion, we will also accept it). You will not be able to use the module itertools.

Training problems: IP089 IP090 IP091 IP092

And also: IP093 IP094 IP095

Exercise 6 · Structured Programming

Something at the level of the the main or extra exercises of practical class #10 (structured programming and incremental development), writing a program that reads from the standard input and writes to the standard output. The problem will have several subtasks and will be suited a decomposition of the code into smaller functions.

Training problems: IP097 IP098 IP099 IP100
