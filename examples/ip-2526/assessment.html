Assessment

The final grade combines the exercises solved during the practical classes, two practical tests and a written exam. No component has a minimum grade.

Eligibility for the exam

  • Attendance of at least 3/4 (75%) of the practical classes.
  • 10% Exercises during classes Problems of the practical classes accepted on Mooshak before each class's deadline.
  • 20% 1st Practical Test Problems in Mooshak, classes #01 to #05.
  • 20% 2nd Practical Test Problems in Mooshak, later classes.
  • 50% Final exam Written exam.

Notes

  • There is no minimum grade requirement for any component.
  • Students will be allowed to improve one of the practical tests (T1 or T2, 20%).

Tests and exam

Exercises during classes

  • Each practical class lists the Mooshak problems you can submit and a deadline. After the deadline the problems stay available on Mooshak, but submissions no longer count.
  • Each practical class is worth 10% of this component. Since there are 11 classes with submissions, you can get the maximum grade without doing all of them.
  • A problem only counts with an Accepted (all tests passed). Even if you solve all problems, the maximum on one class is 100%; solving the main exercises is always enough for 100%.
  • Talking to the professors and colleagues is encouraged, but any direct help from colleagues or LLMs must be acknowledged in the comments of the code you submit.
